With priority lanes on and the Redis broker, an idle stream subscription now waits on the primary and the backfill stream in one read. A production message that arrives during the wait is picked up at once. Brokers gain a `read_blocking_streams` method that reads several streams in one call and returns the messages keyed by stream. The Redis broker serves it with one blocking `XREADGROUP` call, and other brokers fall back to reading the streams one at a time.
