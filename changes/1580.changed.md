`protean schema render --indexes` now rejects an unknown `--dialects` value instead of quietly rendering it with the SQLite dialect. A misspelt dialect used to produce a plausible-looking `.sql` file, named and headed for the dialect that was asked for, full of DDL for the wrong database. The accepted values are `postgresql`, `sqlite`, `mssql`, `mysql` and `mariadb`. (#1580)

**Migration:** [`protean schema render --indexes` rejects an unknown dialect](https://docs.proteanhq.com/reference/migration/v0-18/#protean-schema-render-indexes-rejects-an-unknown-dialect)
