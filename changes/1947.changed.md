**Breaking.** When two query-handler classes read the same query with `@read`, `domain.init()` now raises `IncorrectUsageError` with the message `Queries cannot be handled by multiple handlers: <query types>`, and `protean check` reports the same error. Before, `domain.init()` accepted the domain, and `domain.dispatch()` sent the query to the first registered handler without a warning. The change ships with no opt-in flag under the Silent Correctness Bug exception in ADR-0004.

**Migration:** [Two query handlers for one query raise at `domain.init()`](https://docs.proteanhq.com/reference/migration/v0-19/#two-query-handlers-for-one-query-raise-at-domaininit)
