Added `protean new --from-model <file>`: build a whole project from a text event model and verify it in one step. It parses the model, creates the project with the example slice off, promotes the model to a slice and writes it, then runs the same checks as `protean verify` (init, check, and the project's tests) against the result and reports the verdict. Parse runs first, so an invalid model aborts before any directory is created. The verify logic is now a callable core (`run_verify`) that a caller runs in-process and maps the exit code from; `protean verify`'s own output and exit codes are unchanged.
