Added the `add-saga-flow` teaching skill to the DX pack. It sequences the `process-manager` element skill into an end-to-end saga. The worked example is a broker-free order-fulfillment flow across Order, Inventory, Payment, and Shipping. One process manager runs it: it reacts to each step's event, issues the next command, and closes on a terminal `end=True` handler, with a compensating path for the failure case. The skill ships runnable before and after assets, one leaving the saga open and one closing it. It declares `PROCESS_MANAGER_UNCLOSED`, the diagnostic `check` reports when a process manager has no `end=True` handler. (#1555)
