Trace validation for the `$all` gap-safe checkpoint: `make verify-specs` now records the watermark the real `_gap_safe_batch` settles on over an out-of-order gap and checks the log against `specs/Checkpoint.tla` with TLC, so the shipped code is shown to conform to the model, not just that the model is sound. Two negative checks keep a green run honest: a log that advances past a still-open gap is rejected as a divergence, and an in-order log with no gap is rejected as under-covered.
