`Engine(test_mode=True).run()` and `protean server --test-mode` no longer stop while a subscription is backing off after an error. A poll loop whose tick raised kept counting its earlier empty tick, so test mode could treat it as idle and stop before the retry. The testing docs now also say that test mode does not wait for a broker to redeliver a nacked message, and give the config that makes the retry happen inside the run.
