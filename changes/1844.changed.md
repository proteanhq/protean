`protean test -c FULL` and `-c COVERAGE` run the tests that need no service on pytest-xdist, as `CORE` does, and the tests that need a service in one process. `--workers` sets the worker count for that first pass, and `--sequential` runs it in one process.

**Migration:** [`protean test -c FULL` runs its service-free tests in parallel](https://docs.proteanhq.com/reference/migration/v0-18/#protean-test-c-full-runs-its-service-free-tests-in-parallel)
