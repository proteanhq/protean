The server, FastAPI and observability guides now take their code from tested examples, and the code that did not run is corrected. The correlation guide's subscribers use `stream=` instead of `channel=`. The outbox guide reads abandoned rows through the provider's outbox repository, because `repository_for("Outbox")` fails. The tuning guide's `sequential_by` handler now handles an event, so its partition key takes effect. The logging quick start no longer fails on a missing folder. The FastAPI, hardening and OpenTelemetry examples define the domain and app they use instead of importing them from `my_app` or `my_domain`.
