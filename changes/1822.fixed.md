[Docs] The order-placing example in the application-tests guide no longer takes the order total from the caller. `PlaceOrder` has no `total` field, and its handler adds up each book's price times the quantity ordered, so the "Order total is calculated correctly" scenario checks the total the domain computes. The handler now rejects an order for an unknown book with "Unknown book: <id>" in place of "Insufficient stock" (#1822)
