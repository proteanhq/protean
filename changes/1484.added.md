Added `examples/reference_app/app/`, a runnable FastAPI reference application on top of the golden-path blog domain in `examples/reference_app/blog.py`. It wires that domain to HTTP, SQLite, and a broker with two endpoints: `POST /posts` creates and publishes a post, and `GET /posts` returns the published-posts feed. The clean-clone path needs only `pip install -r requirements.txt` and `uvicorn app.api:app`: SQLite on disk and the in-process inline broker, with synchronous command and event processing so a `POST` fills the feed before the request returns. The app loads the blog domain by file path and applies its own `domain.toml` in the app subfolder, so the config never leaks into the `python blog.py` quickstart. The same `domain.toml` switches to PostgreSQL and Redis through environment variables, with an optional `docker-compose.yml` for the services. An unmarked test drives the app over HTTP with `TestClient`, checks the validation-failure 400, and guards against config leaking into the quickstart.
