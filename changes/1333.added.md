Diagnostics can now name the command that fixes them. Where a deterministic command clears a failure, the diagnostic carries a `resolving_operation` (a structured `{command, args}` an agent runs directly, plus a rendered string for humans). The first pairing is the new `IR_STALE` code, produced by `staleness_diagnostic()` from a staleness result and resolved by `protean-check-staleness --fix`. A code whose failure no command resolves omits the field.
