**Breaking.** When the outbox is on, the server now stops at startup with a `ConfigurationError` if a managed database provider has no outbox table. The error names the provider and says to run `protean db setup` or `protean db setup-outbox`. Before, the server started, and its outbox processor failed on every tick with the database's own "no such table" error. The startup check asks the database whether the table exists. Any other error, raised while building the outbox's database access object or while asking the database, such as a failed connection, now reaches the caller as it is. Before, the check reported an error from building the access object as a missing outbox table.

**Migration:** [The server stops when an outbox table is missing](https://docs.proteanhq.com/reference/migration/v0-19/#the-server-stops-when-an-outbox-table-is-missing)
