Every Python example in the command-handler, event-handler, application-service, domain-service, add-domain-service-flow, repository and message-enrichment skills now runs, and `check` reports nothing on their assets. A domain service flow persists one aggregate per handler. The other aggregate changes through an event and a command, in the skills, the domain services guide and tutorial chapter 13. The skills now say what the Unit of Work does: it can hold several aggregates, a nested one joins the outer one, and a version conflict re-runs the whole handler up to 4 times. They no longer claim that a public domain service helper raises `RecursionError`, or that leaving out `super().__init__()` unwires invariants. The command handler and event handler option tables list every option with its default, and message-enrichment covers `@domain.aggregate_enricher`.
