The `protean dx` pack now ships the full set of teaching skills and their pattern-reference rules. It previously carried only the `protean-overview` placeholder. All 35 skills from the developer-experience source move under `src/protean/dx/pack/skills/`, each keeping its `SKILL.md`, runnable `assets/` examples, and deep-docs `references/`, plus the 12 cross-cutting pattern files under `src/protean/dx/pack/rules/`. Every `SKILL.md` is relicensed to the framework's Apache-2.0. They travel inside the wheel as package data, ready for the follow-up work that wires `protean dx` and the MCP server to read them.
