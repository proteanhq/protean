Trace validation for the recovery protocol: `make verify-specs` now records the real `EventStoreSubscription` failure-recovery path as it runs and replays the log against `specs/Recovery.tla` with TLC, so a recorded run of the shipped record-before-advance path is checked to conform to the model, not just that the model is sound. A fresh trace must both conform and witness a crash after the record but before the durable flush that re-reads the failed message. Two negative checks keep a green run honest: a log that advances past a failed position with no durable record is rejected as a divergence, and a log with no crash redelivery is rejected as under-covered.
