Trace validation for the recovery protocol: `make verify-specs` now records the real `EventStoreSubscription` failure-recovery path as it runs and checks the log against `specs/Recovery.tla` with TLC, so the shipped record-before-advance code is shown to conform to the model, not just that the model is sound. A fresh trace must both conform and witness a crash between record and advance that re-reads the failed message. Two negative checks keep a green run honest: a log that advances past a failed position with no durable record is rejected as a divergence, and a log with no crash redelivery is rejected as under-covered.
