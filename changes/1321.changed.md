`protean new` now scaffolds a minimal walking skeleton instead of a broad demo. The example aggregate is trimmed to one slice that shows both paths end to end: `CreateExample` → `ExampleCreated` → an `ExampleProjector` that writes the `ExampleSummary` read model. The `activate`/`archive` transitions, the standalone event handler, the custom repository, and the unrelated `Address` value object are gone. The scaffold now also ships two passing tests for that slice, and `pytest` (via `make test`) runs green on a fresh project. Previously a new project's test suite was empty, so `protean test` passed without running anything.

The generated `tests/conftest.py` initialises the domain through a session-scoped autouse fixture instead of `pytest_sessionstart`, so a plain `pytest` / `make test` (driven by `testpaths`) sets up the domain context; the old hook only fired when the collection path passed through the package's test directory.
