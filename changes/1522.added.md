`protean dx build-plugin` renders the packaged teaching skills into a Claude Code plugin. It writes a `.claude-plugin/marketplace.json` at the repo root and a `plugins/protean/` tree (a `plugin.json` stamped to the framework version, plus each skill's `SKILL.md` and its assets and references, and the shared reference pages the skills link to), all projected byte for byte from the pack under `src/protean/dx/pack/skills/`. A Claude Code user installs it with `/plugin marketplace add proteanhq/protean` then `/plugin install protean@proteanhq`. `build-plugin --check` is the drift guard: it re-renders in memory and exits non-zero when the committed tree is missing a file, stale, or carries an orphan.
