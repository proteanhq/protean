`ir diff` now classifies a change to a `Dict` or `List` field's value type. Moving a field from `Dict()` to `Dict(value_type=ValueObject(TierPrice))` used to give no entry in the compatibility report, and the command exited `2`. Adding, changing or removing a value type is now a breaking `field_type_changed`, with both value types in the message (`unset` for none). A published event lists it as `contract_field_type_changed`, and a `renamed_from` rename that changes the value type reports `field_type_changed` in place of `field_renamed`.

**Migration:** [New in `ir diff`: value type changes on `Dict` and `List` fields](https://docs.proteanhq.com/reference/migration/v0-19/#new-in-ir-diff-value-type-changes-on-dict-and-list-fields)
