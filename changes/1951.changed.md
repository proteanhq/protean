**Breaking.** Creating an event or command whose class is registered with `abstract=True` now raises `NotSupportedError` with the message `<Name> class has been marked abstract and cannot be instantiated`, the same error an abstract aggregate or value object raises. Before, the event or command was created, and passing the command to `domain.process()` failed later with an `AttributeError`. A concrete subclass of an abstract event or command is created as before. `MessageRouter.command_handler_for` now raises `ConfigurationError` naming the command class when it receives a command instance with no aggregate. Before, it raised `AttributeError`.

**Migration:** [Abstract events and commands cannot be created](https://docs.proteanhq.com/reference/migration/v0-19/#abstract-events-and-commands-cannot-be-created)
