Added a migration note for the 0.17 transaction change to the [0.17 migration guide](https://docs.proteanhq.com/reference/migration/v0-17/). A Unit of Work is now one real database transaction, so a nested Unit of Work joins the outer one (a nested rollback now dooms the whole transaction) and external I/O inside a Unit of Work holds database locks for the length of the call. The note covers both, what the previous model was silently costing, and how to find affected code.
