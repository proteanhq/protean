A `$all` subscription no longer waits `gap_timeout_seconds` and logs an abandoned gap at each snapshot's `global_position`. A `$all` subscription also no longer stops at a read that ends in snapshot rows: it used to read the same snapshot rows on every tick, and a run of `messages_per_tick` snapshot rows stopped it for good. The gap check now counts snapshot rows as present, so the subscription steps over them at once, and a tick that moves past them counts as activity for the idle backoff. A real gap next to a snapshot is still held and then abandoned as before.
