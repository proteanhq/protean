Outbox reconciliation now rebuilds the external-broker rows of a `published` event. When a crash lost a published event's outbox rows, `protean outbox reconcile` and the server's startup sweep restored only the internal-broker row, so the event never reached the brokers in `[outbox].external_brokers`. Reconciliation now also creates one row per external broker, with the same `message_id` and `partition_key` the unit of work would have written. It reads the event class's current `published` flag and the current `external_brokers` list. A broker added to `external_brokers` after the event was written is not back-filled. The count that `reconcile_outbox` returns, and that the command prints, now includes these external rows.
