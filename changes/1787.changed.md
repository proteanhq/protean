**Breaking.** `domain.init()` now rejects a `sequential_by` value on a process manager that is not a boolean. Before, any truthy value turned partitioning on, so a field name such as `sequential_by="order_id"` worked like `True` and the IR carried a string the schema does not allow. The error says the option takes a boolean.

**Migration:** [`sequential_by` on a process manager must be a boolean](https://docs.proteanhq.com/reference/migration/v0-18/#sequential_by-on-a-process-manager-must-be-a-boolean)
