[IR] Deprecate `generate_proto_schemas()`, and `generate_proto_schema()` called without `import_path`. Both raise `RemovedInProtean020Warning` and are removed in 0.20.0; call `write_schemas(..., fmt="protobuf")` instead. Until then, these calls raise `ValueError` naming both classes when two referenced value objects or entities with one class name would be copied into one file, or a referenced class has the name of the file's own element. Before, the generator kept one of the two messages and the other class's fields were lost. A file that nests the members of a reference cycle raises the same error. (#2037)

**Migration:** [The standalone `.proto` generators are deprecated](https://docs.proteanhq.com/reference/migration/v0-19/#the-standalone-proto-generators-are-deprecated)
