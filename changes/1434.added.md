Added the `UNSOURCED_PROJECTION_FIELD` fitness function. It flags a projection field that no projector write fills, catching a dead read-model column that renders and carries a type but nothing ever populates. The check reads what projector methods write. A `**kwargs` construction or bulk `update(...)` disables it for the whole projection, a projection with no observed write at all is skipped entirely, and the identity field is exempt. A `del` of a field, or a write on one of the handler's own parameters (`self.field = ...`), does not count as filling the field. It works from observed writes, so it is advisory: when a projector writes some fields, a sibling field filled only through a path it cannot follow (a helper, a dict splat) can still be flagged.
