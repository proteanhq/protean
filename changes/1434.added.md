Added the `UNSOURCED_PROJECTION_FIELD` fitness function. It flags a projection field that no projector write fills, catching a dead read-model column that renders and carries a type but nothing ever populates. The check reads what projector methods write. A `**kwargs` construction disables it for the whole projection, a projection with no observed write at all is skipped entirely, and the identity field is exempt. A `del` of a field, a write on one of an `@on` handler's own parameters (`self.field = ...`), and a write whose name is not a field of the projection do not count as filling a field. It works from observed writes, so it is advisory: when a projector writes some fields, a sibling field filled only through a path it cannot follow (a helper, a dict splat, a bulk `update(...)`) can still be flagged.
