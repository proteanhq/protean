Added `make test-audit`, which runs the core suite and writes `.test-audit/report.md` and `report.json`. The report lists tests whose covered arcs are a subset of another test's, tests that reach into private state or say they exist for coverage, the 50 slowest tests, and tests that fail only in a random order (with the seed). It deletes nothing. `pytest-randomly` joins the `test` group and is off by default through `-p no:randomly` in `addopts`, so the suite's usual order does not change. The broken `make cov` target is removed; `make test-coverage` does what it meant to do.
