Added `make test-audit`, which runs the core suite and writes `.test-audit/report.md` and `report.json`. The report lists tests whose covered arcs are a subset of another test's, tests that reach into private state or say they exist for coverage, the 50 slowest tests, and tests that fail only in a random order (with the seed). It changes no test and writes only under `.test-audit/`. `pytest-randomly` joins the `test` group and is off by default through `-p no:randomly` in `addopts`, so `protean test`, CI and `make mutation` keep the suite's usual order. The broken `make cov` target is removed; `make test-coverage` does what it meant to do.
