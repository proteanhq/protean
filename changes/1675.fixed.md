Fix the aggregate, entity, value-object and add-field teaching skills, and the entities and value objects guides, so every example in them runs. They now configure elements through decorator options only and say that an inner `class Meta` is ignored. Entity inheritance uses an undecorated `BaseEntity` base, because entities take no `abstract` option. Association helpers are called with keyword arguments (`get_one_from_items(id=...)`), and a miss is caught as `ObjectNotFoundError`. Another aggregate is referenced through an `Identifier` field, not a `Reference`. Repository examples use `add()`, since `save()` and `remove()` do not exist. The invariants page describes when invariants run: at the end of `__init__` and on every field assignment, not before persistence. Nested value objects are passed as objects, money fields are `Decimal(precision=19, scale=4)`, and `Domain()` replaces `Domain(__name__)`.
