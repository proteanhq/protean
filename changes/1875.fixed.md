`@domain.upcaster(event_type=..., from_version=..., to_version=...)` has overloads for the bare and the called form, so mypy keeps the decorated class's type instead of inferring `type[Never]`. The class-taking overload of every element decorator also accepts options, so `domain.upcaster(MyUpcaster, event_type=..., from_version=1, to_version=2)` type-checks.
