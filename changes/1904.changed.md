**Breaking.** Every element that takes `part_of` now checks the kind of element it names. An entity accepts an aggregate or an entity; an event or command an aggregate or a process manager; a database model an aggregate, an entity or a projection; a query or query handler a projection; every other element an aggregate. A class of the wrong kind raises `IncorrectUsageError` when the element registers, naming the element, the target and the kinds it accepts. Before, a value object, application service, database model, event or command tied to the wrong kind registered without complaint, and other wrong targets failed later with an `AttributeError`, `TypeError` or bare `AssertionError`. A string `part_of` resolves against the same kinds, so an entity can now name a parent entity by string and an event or command can name a process manager.

**Migration:** [`part_of` must name the right kind of element](https://docs.proteanhq.com/reference/migration/v0-18/#part_of-must-name-the-right-kind-of-element)
