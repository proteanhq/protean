**Breaking.** `BaseProvider.has_capability`, `has_all_capabilities` and `has_any_capability` are removed. Check a database provider's flags with `DatabaseCapabilities.RAW_QUERIES in provider.capabilities`, and check for any of a set with `provider.capabilities & flags`. `DatabaseCapabilities` gains three flags that no convenience set includes: `NATIVE_CLAIM` (declared by PostgreSQL), `BOUNDED_DELETE` (memory, SQLite, PostgreSQL, MSSQL and Elasticsearch) and `FILTERED_CLAIM_CANDIDATES` (SQLite, PostgreSQL, MSSQL and MySQL). `SqliteProvider` now defines its own `capabilities`.

**Migration:** [Provider capability helpers removed](https://docs.proteanhq.com/reference/migration/v0-19/#provider-capability-helpers-removed)
