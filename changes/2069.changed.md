**Breaking.** `domain.brokers[name]` now returns a `Broker` service from `protean.infra.broker`, which wraps the broker adapter and keeps it as the Internal `_adapter` attribute. A broker adapter implements the new `BrokerPort` Protocol, declared as `class MyBroker(BaseBroker, BrokerPort)`, and its methods carry the Port's public names. `health_stats()` is now `health()` and returns the same envelope. `info()` is now `consumer_groups()`, which returns `ConsumerGroupInfo` records keyed by group name; the Redis broker drops its stream-keyed copy and the inline broker drops `in_flight_messages`, `failed_messages` and `dlq_messages`. `ensure_connection()` is now `reconnect()`, `_data_reset()` is now `clear()`, `_ensure_group(group_name, stream)` is now `create_group(stream, consumer_group)`, and `_reclaim_idle_pending(group_name=...)` is now `reclaim_idle_pending(consumer_group=...)`. `read()` takes `limit` in place of `no_of_messages`, returns `BrokerMessage` records that unpack as `(id, payload)`, and takes `new_messages=True` in place of the `_get_next` hook. `ack()` and `nack()` take `message_id` in place of `identifier`. An adapter reads its settings from `config` in place of `conn_info`. The service has no `redis_instance` attribute; call `get_connection()`. `Brokers` moved from `protean.adapters.broker` to `protean.infra.broker`.

**Migration:** [`domain.brokers` returns `Broker` services](https://docs.proteanhq.com/reference/migration/v0-19/#domainbrokers-returns-broker-services)
