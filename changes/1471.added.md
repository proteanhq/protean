Added `protean.scaffold.model_parser`, the textual event-model grammar of ADR-0041. `parse_model` reads a one-slice text model into a slice-shaped IR fragment (aggregate, command, event, and an optional projection and projector). The fragment reuses the IR's own field model, so there is one field vocabulary. The parse is deterministic, infers nothing, and reports every violation with the 1-based line of the offending token via `ModelParseError`. `emit_model` reads a full IR and a cluster FQN and writes grammar text back for the covered subset. On a cluster the grammar cannot express it raises `ModelEmitError`, so it never drops a participant in silence. A build-time conformance test round-trips a real `to_ir()` slice through emit and parse and matches the ADR worked example, so the grammar stays aligned with the renderer's vocabulary with no live sync. This is the parser half of `protean new --from-model` (#1347); the generator that promotes a fragment to a project is #1472.
