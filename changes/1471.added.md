Added `protean.scaffold.model_parser`, the textual event-model grammar of ADR-0041. `parse_model` reads a one-slice text model into a slice-shaped IR fragment (aggregate, command, event, and an optional projection and projector). The fragment reuses the IR's own field model, so there is one field vocabulary. The parse is deterministic, infers nothing, and reports every violation with its line number via `ModelParseError`. `emit_model` reads a full IR and a cluster FQN and writes grammar text back for the covered subset. On a cluster the grammar cannot express it raises `ModelEmitError`, so it never drops anything in silence: a field type or constraint outside the grammar, a shape it has no room for, or behaviour it carries no syntax for (a non-default element option, a declared invariant, a published event, a domain identity other than the default) is refused rather than emitted and quietly lost on the way back. A build-time conformance test round-trips a real `to_ir()` slice through emit and parse and matches the ADR worked example, so the grammar stays aligned with the renderer's vocabulary with no live sync. This is the parser half of `protean new --from-model` (#1347); the generator that promotes a fragment to a project is #1472.
