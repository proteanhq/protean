`AGGREGATE_TOO_LARGE` now says it counts the entities in an aggregate's cluster.
Its text used to say fields, which did not match the check or the
`[lint] aggregate_size_limit` setting. `COMMAND_NOT_IMPERATIVE` no longer
reports ordinary commands such as `CloseTicket`, `EscalateTicket`,
`RestockProduct` and `ReopenTicket`. The list of verbs a command name can start
with now includes these and other common command verbs.
