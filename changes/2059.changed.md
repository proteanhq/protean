**Breaking.** Causation tracing and the event store integrity check moved out of the event store port. `domain.event_store` now has `trace_causation`, `trace_effects`, `build_causation_tree` and `verify`, and the adapter methods of the same names call the service, so they read the domain's event store instead of the adapter they are called on. `CausationNode` moved to `protean.infra.causation`, and `IntegrityReport` and `IntegrityViolation` moved to `protean.infra.integrity`. The six `VERIFY_*` constants on `BaseEventStore` are replaced by the `ViolationKind` string enum, whose values are the same strings, so `protean eventstore verify --json` output does not change. `build_causation_tree` now writes a node's `time` with `isoformat()`, the format the Observatory already used, so a `datetime` gives `2026-04-01T12:00:00+00:00` instead of `2026-04-01 12:00:00+00:00`.
