A run-to-run stability metric for the comparison-eval harness under `tests/eval/` (kept out of the wheel): run a task `n` times for one approach and report how often it built the same structure (the identical-result rate over the IR element-signature sets, plus the count of distinct structures) and how the correctness score spread (mean, population standard deviation, min, and max). The deterministic approach is a zero-variance guard that re-scaffolds the gold in core CI; the context-driven variance number comes from the opt-in live lane.
