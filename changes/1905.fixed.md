A database model can now name its aggregate, entity or projection by string,
as in `@domain.database_model(part_of="Order")`. The string resolves at
`domain.init()`, so the model can be declared before its target. Before, the
registration failed. The field check and the duplicate-model check now run at
`domain.init()` for a string target, with the same errors a class target
raises at registration.
