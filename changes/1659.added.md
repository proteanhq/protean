Added `get_or_none()` to the event-sourced repository. It takes the same arguments as `get()`, including `at_version` and `as_of`, and returns `None` where `get()` would raise `ObjectNotFoundError`, for example when there is no stream for the identifier, the version is past the end of the stream, or the time is before the first event. Every other error still raises. Each call emits one `protean.repository.get_or_none` span. (#1659)
