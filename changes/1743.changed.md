The stream categories and subscriptions pages, the "Connect Concepts Across Domains" pattern and the "Calling External Systems from Handlers" pattern no longer show an event handler that handles another aggregate's events to change its own aggregate. `protean check` reports a handler whose `part_of` aggregate does not own an event it handles as `EVENT_HANDLER_FOREIGN_EVENT`. Each now shows the event handler on the aggregate that raises the event, issuing a command that the other aggregate's command handler applies and skips when it has already seen it. The facet-sync example applies contact, plan and flags in one command handler method, and runs from `docs_src` with tests. The explicit stream category examples now use a `@handle("$any")` handler.
