`Cache.get_all` is now the private, unpaginated `Cache._get_all`. It returns every matching entry in key order and no longer takes `last_position` or `size`. A cache is for point reads by key, and offering offset pagination over a match set invited use it cannot support: on Redis every call scanned the whole keyspace and deep paging was quadratic. `_get_all` is now scoped to what it is good for, a bounded utility for tests and small stores; page large projection sets through the projection's repository instead. `Cache.count` on Redis now dedupes its scan, so it no longer overcounts a key `SCAN` returns more than once.
