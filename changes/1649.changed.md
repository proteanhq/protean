**Breaking.** `domain.init()` now rejects a `sequential_by` value on an event handler or command handler that is not a non-empty field name. Projectors, which accept the option for the first time, get the same check. On event and command handlers, `sequential_by=True` used to fail with a confusing missing-field error, and `False` or `""` were silently ignored. The error now says these handlers take a field name and that the boolean form is for process managers.

**Migration:** [`sequential_by` on a handler or projector must be a field name](https://docs.proteanhq.com/reference/migration/v0-18/#sequential_by-on-a-handler-or-projector-must-be-a-field-name)
