A `[lint].command_verbs` list in `domain.toml` adds a project's own verbs to the ones `COMMAND_NOT_IMPERATIVE` accepts, so `command_verbs = ["adjust"]` lets `AdjustStock` pass. Matching ignores case and keeps the CamelCase boundary rule. A value that is not a list of non-empty alphabetic words makes `Domain.check()` and the IR build raise `ConfigurationError`, `protean check` exit `2`, and `protean verify` exit `4` with `INVALID_LINT_CONFIG` (#1872)
