An outbox worker whose lock expired no longer releases a row, marks it failed or abandons it after another worker claimed it. Each claim now adds one to the row's `_version`, and the worker checks that version before each of these writes. A refused write changes nothing and logs `outbox.message_already_claimed` at WARNING. Before, the write cleared the other worker's lock, so a third claim could publish the row while the other worker published it too.
