Added the `metadata.diagnostic_codes` contract for DX-pack skills: a skill declares the diagnostic codes it teaches in its `SKILL.md` frontmatter, and the framework reads them back through two new `protean.dx` functions, `skill_diagnostic_codes` (a skill's declared codes) and `diagnostic_code_skills` (the reverse index, each code to the sorted skills that teach it). A diagnostic built by `build_diagnostic` now carries an optional `teaching_skills` list naming the skills that teach its code, present only when a skill declares it and omitted when the pack is absent. The read path is dependency-free and tolerates a pack-stripped install.
