Added `protean.ir.diagnostics`, one place that holds every `protean check` / IR diagnostic code and its metadata (category, level, one-line meaning, rationale, and fix), plus a typed `Diagnostic` wire shape and a `build_diagnostic` helper the producers build their records through. Diagnostic codes are now a stable public identifier: renaming or removing one is a breaking change, guarded by a golden code-set snapshot test, and a source scan fails the build if any code string is hard-coded outside the registry. The wire output (IR JSON, SARIF, and `check` results) is unchanged.
