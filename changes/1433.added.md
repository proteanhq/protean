Materialized `raises` and `invokes` edges into the IR under a new `method_edges` key on the element that owns each method, and bumped the IR schema to v0.2.0. `raises` (on aggregates and entities) lists the events a method raises, derived by co-location, so it can over-report. `invokes` (on command handlers, event handlers, projectors, and process managers) lists the element methods a handler method calls, matched by name against the methods in scope, so it can be incomplete. Both are read from the source as written, so treat them as an approximate guide to the domain's behavior. `protean ir diff` reports a changed edge once under the owning element, and a baseline stamped `0.1.0` now reports a version mismatch and must be regenerated.
