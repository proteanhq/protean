**Breaking.** `protean new` no longer writes a `migrate` target into the generated `Makefile`, for any database. The target only printed "Add your migration command here". A project on `postgresql`, `sqlite` or `mssql` gets `db-migrate`, `db-upgrade` and `db-check` instead. The `--dry-run` list, and the list that `protean.scaffold.create_project` returns, now include each empty folder the command creates, with a trailing `/`, such as `migrations/versions/`. Before, both lists held files only. Projects generated before 0.19 are unchanged.

**Migration:** [`protean new` drops the `migrate` target and lists empty folders](https://docs.proteanhq.com/reference/migration/v0-19/#protean-new-drops-the-migrate-target-and-lists-empty-folders)
