The deprecation warnings for the `is_event_sourced=` aggregate option and the `published` command option now point at the line in your code that registers the element. Before, the `is_event_sourced` warning pointed at a file inside Protean, and the `published` warning pointed at Protean's own registration code. This holds for `@domain.aggregate` and `@domain.command` on a class, `domain.aggregate(Cls, ...)`, and `domain.register(Cls, ...)`.
