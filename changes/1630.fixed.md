The deprecation warnings for the `is_event_sourced=` aggregate option, the `published` command option, and email element registration now point at the line in your code that registers the element. Before, these warnings pointed at Protean's registration code. This holds for `@domain.aggregate`, `@domain.command` and `@domain.email` on a class, `domain.aggregate(Cls, ...)`, `domain.command(Cls, ...)`, and `domain.register(Cls, ...)`.
