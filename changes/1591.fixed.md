Fixed two documentation defects in the DX pack's skills. The event-sourced-aggregate example `es_aggregate_with_entities.py` defined a `Money` value object that nothing used, even though the file's header advertised value objects inside event-sourced aggregates; `LineItem.unit_price` now holds `Money` and the `ItemAdded` handler builds it during replay. The add-field example `add_simple_field.py` had the same problem with its `ContactInfo` value object, which `Customer` now embeds instead of duplicating as primitive fields. A new test sweep, `test_every_value_object_is_referenced`, asserts that every value object defined in a pack asset is referenced by that asset, so an orphan cannot come back. (The `model` vs `database_model` naming was already corrected on the `aggregate` configuration page.) (#1591)
