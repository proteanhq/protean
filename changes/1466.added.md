Added `protean.scaffold.create_project`, a callable core that scaffolds a new project (name validation, target resolution, `--force` clear, copier render, manifest, and `AGENTS.md`) and returns the sorted list of project-relative paths it created. It supports a `dry_run` mode that renders into a temp directory to enumerate the exact files an apply would produce while touching nothing at the target. `protean new` is now a thin wrapper over it, so the MCP server, tests, and other programmatic callers can create a project without going through the CLI.
