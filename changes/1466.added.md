`protean.scaffold.create_project` scaffolds a new project from Python, without going through the CLI. It owns the name validation, target resolution, `--force` clear, copier render, manifest, and `AGENTS.md`, and returns the sorted project-relative paths it created. Pass `dry_run=True` and it renders into a temp directory instead: you get back the same list of paths an apply would produce, and nothing is written at the target. `protean new` is now a thin wrapper over it, so the MCP server, tests, and other programmatic callers can create a project the same way the CLI does.
