[Docs] The `domain.toml` blocks on the adapter reference pages now come from files a test loads, each checked at the adapter that reads its keys. The connection keys for PostgreSQL, SQLite, Redis, Message DB and Elasticsearch read `DATABASE_URL`, `REDIS_URL`, `MESSAGE_DB_URL` or `ELASTICSEARCH_HOST` with the documented value as the default; the MSSQL and MySQL URIs keep their literal form with the password from `MSSQL_PASSWORD` or `MYSQL_PASSWORD`. The two Redis cache blocks that set `TTL` from `CACHE_TTL` now also show the required `URI`. (#2092)
