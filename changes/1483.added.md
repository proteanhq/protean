Added `examples/reference_app/blog.py`, the canonical golden-path domain: a blog `Post` aggregate with a `publish()` method, a `PublishPost` command and handler, a `PostPublished` event and handler, and a `PublishedPostsFeed` projection and projector. It shows the full write-then-read arc with the smallest domain a reader can hold in their head. Importing the module only defines the domain; the in-memory sync demo that prints the arc lives behind an `if __name__ == "__main__"` guard, so `python examples/reference_app/blog.py` runs it with nothing installed beyond `protean`. A `no_test_domain` test loads the module by path and exercises the command, the event handler, and the projection query. This is the base the epic's later FastAPI app, docs quickstart, and README guard build on.
