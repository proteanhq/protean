The MySQL and MSSQL providers now check for their driver at `domain.init()`. When the driver cannot be imported, `domain.init()` raises a `ConfigurationError` that names the database's configured name, the driver and the extra to install (`protean[mysql]` or `protean[mssql]`). It used to raise the driver's own `ModuleNotFoundError` from SQLAlchemy. A `database_uri` that names PyMySQL or pyodbc, and a plain `mssql://`, are checked for that driver. A plain `mysql://` or `mariadb://` is checked for mysqlclient, which SQLAlchemy uses for those URLs, and the error asks you to add `+pymysql` to the URL and install the extra. A `database_uri` that names another driver goes to SQLAlchemy as written.
