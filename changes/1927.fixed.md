`protean schema generate` now types the values of a `Dict(value_type=ValueObject(...))` field. JSON Schema refers to the value object from `additionalProperties`, Avro writes a `map` of the value object's record, and Protobuf writes `map<string, <ValueObject>>`. Each format still defines the value object once when another field also uses it. The IR records the value object's full name as `target` on the `Dict` field, so the IR schema moves to `0.4.0`. An untyped `Dict()` keeps its old output.
