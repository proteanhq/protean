`--format` is now validated on `protean ir diff`, `ir show`, and `ir check`. An invalid value fails with a message listing the valid formats, where it used to fall through to the default format silently.

**Migration:** [`protean ir` rejects an unknown format value](https://docs.proteanhq.com/reference/migration/v0-18/#protean-ir-rejects-an-unknown-format-value)
