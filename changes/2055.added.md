**Breaking.** Added `EventStoreCapabilities`, a flag that lists the guarantees an event store makes, and a `capabilities` property on the memory store (`CONSISTENT`) and the Message DB store (`PRODUCTION`). `capabilities` is abstract on `BaseEventStore`, so an event store that subclasses `BaseEventStore` directly must now define it: creating an instance of a subclass without it raises `TypeError`.

**Migration:** [An event store written outside Protean must define `capabilities`](https://docs.proteanhq.com/reference/migration/v0-19/#an-event-store-written-outside-protean-must-define-capabilities)
