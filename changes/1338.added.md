Added an annotation layer to `protean docs generate --type=event-model`. Human notes for the event model live in `.protean/annotations.toml`, a TOML file keyed by element FQN (`[annotations."myproj.example.aggregate.Order"]` with a required `note` string and an optional `owner`, per ADR-0032). On render, each note merges into the slice section for the element it keys: a note on an aggregate, command, event, or a consumer drawn in a slice shows after that slice's Given-When-Then and before its diagram. A key that matches no drawn element (a fact event, or a note orphaned by a rename) is listed in an "Unmatched annotations" section at the end, so no note is dropped in silence. `--annotations <path>` overrides the default file; an explicit path that does not exist, or a malformed file, aborts the command before any output is written. With no annotations file present the render is unchanged. In `--format=mermaid` the flowchart body is untouched and only the unmatched report is appended, since notes are Markdown prose and cannot sit inside a raw flowchart.
