The startup reconcile sweep and `protean outbox reconcile` now rebuild the outbox row of every event-sourced aggregate's event in the scanned window that has no internal outbox row. Before, they repaired only when the newest such event was missing its row, so an event whose row was lost in a crash stayed unpublished once another process in the same domain committed a later event. Every run now reads the whole window and looks up the outbox rows of its events in batches.
