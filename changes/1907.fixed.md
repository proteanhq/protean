**Breaking.** The startup reconcile sweep and `protean outbox reconcile` now rebuild the outbox rows of every event-sourced aggregate's event in the scanned window that has no internal outbox row and is inside the cleanup retention, including the external-broker rows of a `published` event. Before, they repaired only when the newest such event was missing its row, so an event whose row was lost in a crash stayed unpublished once another process in the same domain committed a later event. When an event-sourced aggregate is on the provider, every run now reads the whole window and looks up the outbox rows of its events in batches.

**Migration:** [Outbox reconciliation repairs every lost row in its window](https://docs.proteanhq.com/reference/migration/v0-18/#outbox-reconciliation-repairs-every-lost-row-in-its-window)
