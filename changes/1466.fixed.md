**Breaking.** `protean new .` and `protean new ..` now raise `ValueError`. A project name has to be a single directory segment, so the `--force` clear can never reach the output folder or its parent. Both names passed validation before and produced a project that could not be installed (`name = "."` in `pyproject.toml`, no package directory under `src/`).

**Migration:** [`protean new .` and `protean new ..` are rejected](https://docs.proteanhq.com/reference/migration/v0-18/#protean-new-and-protean-new-are-rejected)
