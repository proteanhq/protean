Type unions in documentation tables now render as `str | None` on the docs site, where they showed a literal backslash (`str \| None`) in 33 rows across the logging, type-checking, hardening, indexes, message-tracing and query-system references. A `|` inside a table cell ends the cell on GitHub even within a code span, so it has to be escaped there, and python-markdown then publishes the backslash. The rows now use a code tag with an HTML entity, which is correct in both.
