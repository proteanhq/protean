Hardened the event-driven and CQRS teaching skills in the DX pack and wired them to the diagnostic contract. Fixed drift against the current API: `event_sourced=True` replaces the deprecated `is_event_sourced` alias, `ValueObject` fields are allowed in projections, custom event-sourced repositories subclass `BaseEventSourcedRepository`, and several error-type and message references now match the framework. Each hardened skill declares the diagnostic codes it teaches under `metadata.diagnostic_codes`, so a diagnostic can point at the skill that teaches its fix.
