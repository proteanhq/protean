**Breaking.** A domain with no environment variable set (`PROTEAN_ENV`, `ENV` and `ENVIRONMENT` all unset) now logs at INFO with colored console output, instead of DEBUG. `domain.init()` followed by a caught `ValidationError` writes no log lines at this default. Only an explicit `PROTEAN_ENV=development` selects DEBUG. Creating a Protean exception no longer logs an `Exception::` line. A provider or broker plugin that fails to load now logs a WARNING, and a plugin skipped because its optional extra is not installed logs a DEBUG line naming the missing module. Set `PROTEAN_ENV=development` or `PROTEAN_LOG_LEVEL=DEBUG` to get the DEBUG lines back.

**Migration:** [A domain with no environment set logs at INFO](https://docs.proteanhq.com/reference/migration/v0-18/#a-domain-with-no-environment-set-logs-at-info)
