**Breaking.** `protean eventstore verify` no longer raises `TypeError` on a Message DB row whose `data` is NULL. It reports the row as `malformed_message` with its stream and position, and the memory store reports the same row instead of passing it. A row whose `data` holds a JSON array, string or number is reported the same way instead of passing. The `message-db` extra now requires `message-db-py` 0.3.5 or later.

**Migration:** [`eventstore verify` reports a message with a NULL body](https://docs.proteanhq.com/reference/migration/v0-19/#eventstore-verify-reports-a-message-with-a-null-body)
