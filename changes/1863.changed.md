Runtime messages no longer contain em-dashes. This covers `protean check` diagnostic messages and the rationale for `AGGREGATE_WITHOUT_COMMAND_HANDLER`, `PROJECTOR_HANDLES_ORPHANED_EVENT` and `QUERY_HANDLER_WITHOUT_QUERY`, plus `protean dx`, `protean ir` and git-hook output, CLI table titles, and some exception and log messages. Each dash is now a colon, a comma or a full stop. Only the wording changes. A script that matches the exact text of one of these messages needs the new wording.
