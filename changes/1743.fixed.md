The stream categories and subscriptions pages, the "Connect Concepts Across Domains" pattern and the "Calling External Systems from Handlers" pattern no longer show an event handler that handles another aggregate's events to change its own aggregate. `protean check` reports `EVENT_HANDLER_FOREIGN_EVENT` when a handler handles an event that a single other aggregate in the same domain defines. Where a page shows a handler changing another aggregate, the handler now sits on the aggregate that raises the event and issues a command to the other aggregate. The full examples on the stream categories page and the two pattern pages show that command handler skipping a command it has already applied. The facet-sync example applies contact, plan and flags in one command handler method, and runs from `docs_src` with tests, as does the same-domain example in "Connect Concepts Across Domains". The explicit stream category examples now use a `@handle("$any")` handler.
