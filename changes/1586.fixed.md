An aggregate with `identity_type = "integer"` now builds its model on the SQLAlchemy providers (SQLite, PostgreSQL, MySQL/MariaDB, MSSQL). Before, building it raised `TypeError: Integer() takes no arguments`. Under the `uuid` strategy an integer identity is a 128-bit number that no SQL integer column holds, so `Domain.init()` now raises `ConfigurationError` for that case. The message names the aggregate and the provider, and points to `identity_strategy = "function"` or `Auto(increment=True)`. The memory and Elasticsearch providers are unchanged.
