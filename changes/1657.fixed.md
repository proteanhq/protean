`reconcile_outbox` and `protean outbox reconcile` now check the newest `limit` messages of `$all` when the event store has gaps in `global_position`. Message DB skips sequence values after a rolled-back insert or after crash recovery. Reconcile used to read only the span of `limit` positions ending at the tail, so it checked fewer than `limit` messages and could leave a lost outbox row unrepaired. A snapshot row counts toward `limit`. On a store with no gaps and no snapshot rows near the tail, reconcile reads the same window as before.
