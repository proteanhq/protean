An aggregate whose `@invariant.pre` rejects its current state can now be saved when it has an `auto_now` / `auto_now_add` field or a registered aggregate enricher. Those save-time writes no longer run the pre-invariants. On a save outside an `atomic_change` block, the post-invariants run once after the stamping and once after each enricher, and a failure raises `ValidationError` whose `location` names the hook.
