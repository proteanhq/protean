The cache conformance suite now lives in `tests/conformance/cache/`, and each of its tests names the `CacheCapabilities` flags it needs. `protean test test-adapter --port cache` runs the real suite, so the report shows passed tests in the `KEY_VALUE`, `TTL` and `PATTERN_MATCH` rows, and a Redis cache also passes `SHARED` and `DURABLE`. The Redis leg runs the suite on Redis through the `cache:redis` pair in `tests/adapters.toml`.
