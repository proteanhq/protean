Single-worker `protean server` and `protean observatory` now apply the `[logging]` section of `domain.toml` (level, format, redaction, `per_logger`, sampling, and the correlation and OpenTelemetry processors). They used to set up console logging before the domain loaded, which made `Domain.init()` skip its own setup. `--log-level` and `--log-format` now override only the level and the format, and the rest of `[logging]` still applies. `--log-config` still replaces everything. A multi-worker supervisor now forwards worker records at the `[logging]` level, so a DEBUG level is no longer dropped. With several `--domain` values, `observatory` applies the first domain's `[logging]`.

**Migration:** [`protean server` and `protean observatory` apply `[logging]`](https://docs.proteanhq.com/reference/migration/v0-18/#protean-server-and-protean-observatory-apply-logging)
