Added the `protean dx` command group. `protean dx install` writes an `AGENTS.md`
and a one-line `CLAUDE.md` bridge into your project, composed from the installed
framework version so a coding agent reads guidance that matches your code. Writes
go through a managed block, so re-running `install` or `refresh` keeps your own
edits around it. `protean dx diff` previews pending changes and writes nothing;
`protean dx check` exits non-zero when a project has drifted from the installed
version, for wiring into CI.
