Added `protean docs generate --type=event-model`, an EventModeling slice-timeline view rendered from the IR. Each aggregate cluster becomes one left-to-right slice: its commands, the aggregate that holds state, the non-fact events it raises, and the downstream consumers of those events (projectors as read models drawn as cylinders, event handlers and process managers as automations drawn as hexagons, with a process manager's `start`/`end` lifecycle shown on its node and edge). `--format=mermaid` emits one combined `flowchart LR` timeline; `--format=markdown` emits one titled `mermaid` fence per slice. The whole render is derived from `to_ir()` alone, matching consumers to a slice's events by the event `__type__`, with no import of domain code and no dependence on the fail-open `method_edges`. The new type is its own view and is not folded into `--type=all`.
