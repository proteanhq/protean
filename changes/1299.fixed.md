Fixed the tutorial's priority-lanes example, which told you to write `priority_lanes = true` under `[server]`. It is a table, so that crashed `Domain.init()` with `AttributeError: 'bool' object has no attribute 'get'`. The examples now show `[server.priority_lanes]` with `enabled = true`, and a bool there now raises a `ConfigurationError` that shows the correct form instead of an AttributeError.

Also fixed a cache `TTL` set from an environment variable. Substitution runs over parsed TOML strings, so `TTL = "${CACHE_TTL|3600}"` reached the adapter as `"3600"`: the memory cache raised `TypeError: unsupported operand type(s) for +: 'float' and 'str'` on the first write, and the Redis cache computed `"3600" * 1000` and asked Redis to expire the key in a 4000-digit number of milliseconds. `TTL` is now coerced once, when the cache is built, and a value that is not a number of seconds raises a `ConfigurationError` naming the cache instead of failing later at the first write. The `protean new` scaffold shipped `CACHE_TTL` in `.env.example` and can now use it again.
