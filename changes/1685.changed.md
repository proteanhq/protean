`protean check --domain=<file>` no longer crashes with a `FileNotFoundError` on a file that declares `Domain(__name__)`. `Domain.check()` now checks such a domain without traversal and logs a warning. A module that raises while `check` traverses the domain's directory now ends the command with a one-line error (exit 2) in place of a traceback.

**Breaking.** A failure to build the IR is now an error in the `Domain.check()` result (status `fail`, `protean check` exits 1) in place of a logged traceback beside a `pass`.

**Migration:** [A failed IR build now fails `check`](https://docs.proteanhq.com/reference/migration/v0-18/#a-failed-ir-build-now-fails-check)
