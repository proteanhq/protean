The frontmatter of the `domain-service` and `query-handler` skills now parses. Their descriptions held an unquoted `: `, so the YAML did not parse and Claude Code ignored the skill. The `application-service` and `event-handler` descriptions are shortened under Claude Code's 1,024-character limit. New tests parse every skill's frontmatter, run the fenced `python` blocks in each skill's `SKILL.md` and `references/*.md` file by file, and run `check` on every skill asset except the ones that show a problem on purpose. A block that is not meant to run starts with a `# fragment` line. Wrong examples that shared a block with their correct version are split into two blocks, so the correct version runs.
