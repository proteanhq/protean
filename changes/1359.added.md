`verify()` on `BaseEventStore` and a new `protean eventstore verify` command run a read-only integrity check over the event store: every row is well-formed, per-stream positions are gapless, `global_position` is strictly increasing, message ids are unique, and no snapshot is malformed or runs ahead of its aggregate stream. A corrupt row is reported, not skipped. The command prints a table (or `--json` result envelope) and exits non-zero on any violation.
