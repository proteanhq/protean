[Testing] Deprecate `protean.integrations.pytest.adapter_conformance`, its `--db`, `--db-provider`, `--db-uri` and `--db-extra` options, and `protean.testing.get_generic_test_dir()`. Importing the plugin and calling the function raise `RemovedInProtean020Warning`, and both are removed in 0.20.0. A new plugin, `tests/conformance/conftest.py`, gives each port a folder under `tests/conformance/` and runs from a source checkout. Each folder holds a placeholder test until its port's suite moves in. The plugin takes `--port`, `--adapter`, `--adapter-config` and `--capability` and gates tests with the `requires` and `requires_any` markers. (#2053)

**Migration:** [The `adapter_conformance` pytest plugin is deprecated](https://docs.proteanhq.com/reference/migration/v0-19/#the-adapter_conformance-pytest-plugin-is-deprecated)
