The docs and DX-pack snippet tests no longer run a Python or TOML block written inside a fence of another language, such as a ```` ```python ```` example inside a ```` ````markdown ```` fence. The extractor now skips every fence in another language through its closing fence and reads a backtick inside a quoted option such as ``` title="`x`" ``` as part of the fence's info string, as the docs build does. The independent block counts also skip the lines inside a fence.
