`Domain.init()` now rebuilds the handler routing tables from scratch on every call. Before, a second `init()` added to the tables from the first one, so a handler removed from the registry, as the adapter conformance pytest plugin does when it clears the registry between tests, still received events. The routing tables also moved out of the event store into the domain, and `domain.handlers_for()`, `domain.projectors_for()` and `domain.command_handler_for()` return the same results as before.
