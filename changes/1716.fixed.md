Some server, observatory, subscription and retry paths dropped errors without a trace. They now log them. The observatory and subscription-status scrapes log a skipped domain, stream, consumer group or handler at debug level. So do a failed handler-retry metric, a teaching skill whose diagnostic codes cannot be read, a health-probe client that disconnects, and an event with a timestamp that is not ISO 8601. A failed stale-consumer cleanup at subscription startup, an invalid `server.version_retry` configuration and an IR build that fails inside `Domain.check()` log a warning. The `server.version_retry` warning is logged once for each distinct `[server]` table. It also covers `max_retries = inf`, which already fell back to the defaults but did so without a warning.
