Errors that some server, observatory, subscription, logging and retry paths used to drop silently are now logged. The best-effort observatory and subscription-status scrapes log a skipped domain, stream or consumer group at debug level. A failed stale-consumer cleanup at subscription startup, an invalid `server.version_retry` configuration, and an IR build that fails inside `Domain.check()` now log a warning. Paths that expect one kind of failure, such as no active domain context or a closed health-check socket, now catch that exception only, so an unexpected error is no longer hidden.
