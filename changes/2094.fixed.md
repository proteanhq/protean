An Elasticsearch host without a port, such as `localhost` or `http://es`, now gets port 9200, the Elasticsearch default. The Elasticsearch 8 client rejected such a host, so `ESProvider` raised `ConfigurationError`. An `https://` URL without a port still gets port 443 from the client. A host that the client rejects no longer has its URL, credentials included, repeated in the `ConfigurationError` message.
