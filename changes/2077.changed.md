**Breaking.** Lookups implement the `LookupPort` protocol in `protean.port.dao`, which replaces `BaseLookup`. The Protocol declares `lookup_name`, `source`, `target`, `database_model_cls` and the constructor. Each adapter's lookup base class declares its own evaluation method, and the memory adapter's lookups no longer define `as_expression()`. `BaseProvider._extract_lookup()` is replaced by `split_lookup_key()` in `protean.utils.query`, which returns the field name and the lookup name, followed by `get_lookup()`. `BaseProvider.REQUIRED_LOOKUPS` is now `protean.port.dao.REQUIRED_LOOKUPS`, and `BaseProvider.validate_lookups()` is removed. `ProviderPort` gains the abstract class method `get_lookups()`. The provider registry raises `ConfigurationError` naming the missing lookups when it loads a provider class that lacks a required lookup, where it logged a warning, and raises `ConfigurationError` when a required lookup is registered as a class that does not subclass `LookupPort`. An unknown lookup still raises `NotImplementedError`, now with a message that names the lookup and the provider.

**Migration:** [`BaseLookup` is now `LookupPort`](https://docs.proteanhq.com/reference/migration/v0-19/#baselookup-is-now-lookupport) and the three sections after it.
