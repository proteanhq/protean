Projects generated by `protean new` now set up their test domain with `DomainFixture`, the same recipe the testing docs teach. Each test runs in its own domain context. After each test, the data in every database, broker and event store is reset (caches are not). When the session ends, the tables are dropped. The generated tests use the database named in `domain.toml`, the same one the app uses, so a test run drops the app's tables too; run `protean db setup` to create them again. Existing projects are unchanged.
