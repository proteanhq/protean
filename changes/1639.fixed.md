`--log-level`, `--log-format` and `--log-config` now reach the worker processes of `protean server --workers N` and `protean server --reload`. Each worker applies them the way the parent does: `--log-level` and `--log-format` override the level and the format of `[logging]`, and `--log-config` replaces `[logging]`. Before this, the workers ignored the flags and used `[logging]` and `PROTEAN_LOG_LEVEL` only.
