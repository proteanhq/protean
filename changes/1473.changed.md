**Breaking.** `protean new`'s dry-run flag is `--dry-run`. `--pretend` and its `-p` short form are gone, and passing either is a usage error. `--pretend` was copier's name for the option; `protean add` already says `--dry-run`, and so does the `create_project` core `protean new` calls. Nothing else about the dry run changed.

**Migration:** [`protean new --pretend` is now `--dry-run`, and it writes nothing](https://docs.proteanhq.com/reference/migration/v0-18/#protean-new-pretend-is-now-dry-run-and-it-writes-nothing)
