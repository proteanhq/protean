Init-time and runtime raises from the domain now carry a stable diagnostic `code`, plus a `location`, `rationale`, and `fix`, alongside their prose message. The codes live in the shared `protean.ir.diagnostics` registry, tagged `kind="raise"` to set them apart from the `protean check` lint rules, and the code survives a pickle round-trip so it is intact when an exception crosses the outbox or broker boundary. See the new [Init-time and Runtime Diagnostics](reference/init-diagnostics.md) reference for the full catalog. A few of these failures are statically detectable and could later grow a matching `protean check` rule under the same code.
