A field declared with `choices` now gets the column type its choices share on SQL databases. A `String` with `choices` keeps its `max_length` (`VARCHAR(n)`, where MySQL and MariaDB used to create `TEXT`), so it can be a unique or indexed column on SQL Server and MySQL. An `Integer`, `Float`, `Boolean` or `Decimal` field with `choices` gets its own column type instead of `VARCHAR`, so an `Integer` with `choices` loads back as an `int`. The MySQL index-width check now counts these columns. Choices of mixed types keep the old column: `TEXT` on MySQL and MariaDB, an unsized `VARCHAR` elsewhere.
