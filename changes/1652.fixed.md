The `protean upgrade-check` reference and the 0.17 migration guide now state what the Unit of Work source checks cover. They read explicit `with UnitOfWork()` blocks only, so they do not see the Unit of Work that `@handle` and `@use_case` methods run in, and they count only some calls as I/O. Run `protean check` for I/O in handler methods, and review `@use_case` methods by hand.
