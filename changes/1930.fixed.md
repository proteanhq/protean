`protean ir show` and every other IR build no longer fail with `AttributeError` when a handler, projector or process manager sets `subscription_type` or `subscription_profile` as a string, such as `subscription_type="event_store"`. The IR records the option's lower-case name, the same value as for the enum member. The v0.4.0 IR schema now accepts any profile name in a subscription's `profile`, so an IR that names a custom profile from `[server.profiles]` validates.
