`protean ir show` and every other IR build no longer fail with `AttributeError` when a handler, projector or process manager sets `subscription_type` or `subscription_profile` as a string, such as `subscription_type="event_store"`. The IR records the option's name in lower case. For a built-in name, this is the same value the enum member records. An unknown type string is recorded as declared, in lower case, and fails schema validation. A custom profile name from `[server.profiles]` is recorded the same way. The v0.3.0 IR schema still accepts only the built-in profile names, so that IR fails schema validation.
