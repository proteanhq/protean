Under `protean server --workers N`, each worker's queue handler now masks every `redact` key set the worker's root logger or its handlers held, on stdlib log record attributes. Before, it masked only the first redaction filter on the root logger. Keys from a second `configure_logging()` call, or from a second redaction filter declared on the root logger in a `dictConfig`, left the worker unmasked. The supervisor's output masked them only when its own handlers held the same keys.
