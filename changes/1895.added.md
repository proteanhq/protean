[CLI] `protean outbox halted` lists the partition keys that an abandoned outbox row halts, with the row's id, its last error and the number of rows waiting behind it (`--json` prints the result envelope). `protean outbox retry <id>` sends a failed or abandoned row back to pending, and `protean outbox discard <id> --reason TEXT` skips it for good. Both refuse any other row, and a row a worker claims while the command runs. `discard` refuses an empty reason. A discarded row gets the new `OutboxStatus.DISCARDED` status: it is never published, it no longer holds its key, and it stays in the outbox for audit with the reason in `last_error`. `Outbox.discard()`, `OutboxRepository.find_halted()`, `OutboxRepository.save_operator_change()` and `OutboxRepository.cleanup_old_discarded()` back the commands.
