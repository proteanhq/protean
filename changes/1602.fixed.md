The projector skill's error-handling and cross-aggregate reference snippets caught the wrong exceptions for a missing projection record. `error-handling.md` caught the bare `Exception`, which also swallows connection errors and validation failures that should propagate so the engine can retry or record the failure. `cross-aggregate.md` caught `NotFoundError`, a class that does not exist in `protean`, so the snippet raised `NameError` on the first miss instead of handling it. Both now catch `ObjectNotFoundError`, the exception `repo.get()` actually raises when a record is absent.
