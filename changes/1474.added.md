`protean dx install` now writes three per-editor files alongside the canonical set: Cursor's `.cursor/rules/protean.mdc` rule file, Copilot's `.github/copilot-instructions.md`, and opencode's `opencode.json` config. Cursor's rule carries MDC frontmatter (scoped to Python files via `globs`) and the composed guidance, rendered as a whole file Protean owns end to end. Copilot's file carries the guidance in an HTML-comment managed block, so it stays co-owned with the user's own instructions. opencode's config manages one `mcp.protean` entry with opencode's launch shape (`type: "local"`, `command: ["protean", "mcp"]`, `enabled: true`) and preserves the user's other keys. All three are idempotent and `dx check` flags any that drift. (#1474)
