[Check] `protean check` now resolves an import written inside a method for the uses after it. Every check that reads method bodies sees such imports: `UNRAISED_EVENT` no longer flags an event a method imports and raises, `HANDLER_PERSISTS_AND_CALLS_OUT` now reports a call made through a client imported inside the handler method, the opt-in `ADAPTER_CALL_IN_DOMAIN` now reports an adapter bound that way, and the IR's per-method `raises` edges now include events imported inside the method.
