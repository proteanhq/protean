`protean test -c PR` runs what a pull request's CI runs: the CORE suite and the adapter suites listed in `tests/adapters.toml`, all under coverage. `-a/--adapter` runs the named adapters in place of that default list, and `--no-core` and `--no-adapters` drop a part. `protean test select-adapters` prints the CI adapter matrix for a list of changed files.
