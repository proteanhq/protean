`protean db migrate` and `protean db check` now match each table by its schema and its name. A custom database model with its table in a second schema, such as `__table_args__ = {"schema": "reporting"}`, is compared in that schema. Before, autogenerate reported such a table as missing and created it a second time, and it dropped an unrelated table of the same name in the provider's schema. Raw indexes of the table are created, checked and rebuilt in its schema, and `protean db check` names the table `reporting.archive`. A provider with one schema gets the same output as before.
