Every runnable example on the domain definition guide and the fields and domain element reference now lives in `docs_src` and runs in CI, with a test that checks what the page says about it. Examples that no longer worked are fixed:

- `DateTime(default="utc_now")` now passes the `utc_now` callable.
- Examples that used `Order`, `OrderPlaced`, `LineItem`, `Statistic` or `Email` without defining them now define them.
- The provider example uses the current lowercase `databases` settings.
- The relationship navigation example adds the comment through the post, so `comment.post` is set.
- The `via` example uses a foreign key name that differs from the default.
- The `suppress_checks` example names a real diagnostic code.
- `to_dict()` outputs include `_version`, and shell outputs no longer show an `ERROR: Error during initialization` log line that Protean does not print.

The fields guide and the field arguments reference no longer warn that `default=[]` shares one list across instances. Protean gives each instance its own shallow copy of a `list` or `dict` default. The container fields page no longer says that appending to a list of value objects is not saved; it is saved.
