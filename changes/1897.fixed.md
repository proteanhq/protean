**Breaking.** A value object's string `part_of` now resolves to the aggregate class at `domain.init()`, as it does for entities, events, commands, command and event handlers, application services and repositories. `IRBuilder(domain).build()` no longer raises `AttributeError` for a value object with a string `part_of` that no `ValueObject` or `ValueObjectList` field embeds, such as one reached only through `Dict(value_type=ValueObject(...))`; the value object now appears in its aggregate's cluster. `domain.init()` now rejects a value-object `part_of` that names no aggregate (a misspelt name, or an entity's name) with the unresolved-reference `ConfigurationError`.

**Migration:** [A value object's string `part_of` must name an aggregate](https://docs.proteanhq.com/reference/migration/v0-18/#a-value-objects-string-part_of-must-name-an-aggregate)
