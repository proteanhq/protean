**Breaking.** Adapters of all four ports now register through one class, `AdapterRegistry` in `protean.infra.registry`, with the instances `providers`, `brokers`, `event_stores` and `caches`. `ProviderRegistry`, `BrokerRegistry`, the `registry` names in `protean.port.provider`, `protean.port.broker`, `protean.adapters.repository` and `protean.adapters.broker`, and the `EVENT_STORE_PROVIDERS` and `CACHE_PROVIDERS` tables are removed. Event stores and caches load from the new `protean.event_stores` and `protean.caches` entry-point groups, so other packages can provide them, and an unknown name in `[event_store]` or `[caches.*]` raises `ConfigurationError` listing the registered names instead of `KeyError`. Loading an adapter class that leaves an abstract method or property unimplemented raises `ConfigurationError` naming each missing member.

**Migration:** [Adapter registries moved to `protean.infra.registry`](https://docs.proteanhq.com/reference/migration/v0-19/#adapter-registries-moved-to-proteaninfraregistry)
