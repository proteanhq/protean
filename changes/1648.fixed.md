Fixed `protean outbox reconcile` and the server's startup reconcile creating outbox rows for messages the domain never outboxes. In an event store shared with another domain, or when the last write was a command or a process manager transition, reconcile treated that message as a lost row, repaired it, and then published it. Reconcile now repairs only events raised by this domain's aggregates on the reconciled provider, walks back past other messages at the tail to find the newest such event, and gives each rebuilt row the same `partition_key` the unit of work would have set. `--limit` counts every message scanned in `$all`, including skipped ones. The disabled-outbox error now says to set `default_subscription_type = "stream"`, and that the older `enable_outbox = true` switch also needs that setting. Rows marked abandoned now record `last_processed_at`, so `cleanup_old_abandoned()` removes them after the retention period.
