Multi-worker (`--workers N`) and `--reload` workers of `protean server` now set up their logging before the domain loads the same way the parent process does. Before, a worker without `--log-level` logged at INFO until its domain loaded, so `PROTEAN_LOG_LEVEL=DEBUG` lost the DEBUG lines written while the domain loaded, and `--log-format` did not apply until then either. `--log-level` still takes precedence over `PROTEAN_LOG_LEVEL`, and `--log-config` replaces both.
