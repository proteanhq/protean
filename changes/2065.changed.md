**Breaking.** `capabilities` is now an abstract property on `BaseCache`, a Provisional API, so a custom cache adapter that does not define it raises `TypeError` when built. Return `CacheCapabilities.LOCAL` or `CacheCapabilities.DISTRIBUTED`, or the flags the adapter supports.

**Migration:** [A custom cache adapter must define `capabilities`](https://docs.proteanhq.com/reference/migration/v0-19/#a-custom-cache-adapter-must-define-capabilities)
