**Breaking.** Value objects now compare and hash by their field values instead of their `to_dict()` output. Two value objects holding `Decimal("9.99")` and `Decimal("9.9900")` are now equal and hash the same, including when the `Decimal` sits in a nested value object. `to_dict()` output is unchanged and still keeps the scale each amount was given. A field's default is now validated and cast like an assigned value.

**Migration:** [Value objects compare their field values](https://docs.proteanhq.com/reference/migration/v0-19/#value-objects-compare-their-field-values)
