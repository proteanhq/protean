Reading, setting or deleting an attribute on `current_domain` with no active domain context fails with an error that says no domain context is active, names the attribute, and points to `domain.domain_context()`. For example, `domain.repository_for(Order).add(order)` with no `with domain.domain_context():` block used to fail with a bare `AttributeError: databases`. The error subclasses `AttributeError`, so `hasattr(current_domain, ...)` and `getattr(current_domain, ..., default)` behave as before.
