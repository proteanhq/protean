A write through a repository outside a domain context, such as `domain.repository_for(Order).add(order)` with no `with domain.domain_context():` block, now raises an error that says no domain context is active and points to `domain.domain_context()`, in place of a bare `AttributeError: databases`. The error subclasses `AttributeError`, so `hasattr(current_domain, ...)` and `getattr(current_domain, ..., default)` behave as before.
