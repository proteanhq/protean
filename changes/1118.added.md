A query can now declare the type its handler returns by subscripting the base: `class GetOrderSummary(BaseQuery[OrderSummary])`. `domain.dispatch` then resolves to that type at the call site, so the result is typed instead of `Any`. This works under both mypy and pyright without the mypy plugin, because it is plain generics and typed overloads on `dispatch`. Declaring the result type is optional; a bare `BaseQuery` subclass keeps dispatching to `Any` at runtime and behaves exactly as before. See ADR-0043. (#1118)
