**Breaking.** On SQLite, MySQL, MariaDB and SQL Server, a repository query that orders by a nullable field now puts NULLs last when ascending and first when descending. PostgreSQL and the in-memory adapter already sorted NULLs this way, so the same query now returns the same order on every supported database. A query that relied on NULLs coming first in an ascending sort on one of those four databases now gets them last.

**Migration:** [Rows written before the upgrade](https://docs.proteanhq.com/reference/migration/v0-19/#rows-written-before-the-upgrade)
