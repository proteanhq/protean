**Breaking, symlinked targets only.** `protean new` refuses a target directory that resolves outside the output directory. `<output-dir>/<name>` being a symlink to somewhere else used to be followed: `--force` cleared files at the link target, and the render wrote them there. The command now stops with a `ValueError`, on apply and under `--pretend`. `protean.scaffold.create_project` raises the same error.

**Migration:** [`protean new` refuses a target symlinked out of the output directory](https://docs.proteanhq.com/reference/migration/v0-18/#protean-new-refuses-a-target-symlinked-out-of-the-output-directory)
