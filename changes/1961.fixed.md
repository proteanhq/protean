A value object that no aggregate cluster places, such as one with no `part_of` that only projections hold, now appears in a top-level `value_objects` section of the IR. Its generated JSON Schema, Avro and Protobuf definitions carry its fields, and `protean schema generate` writes it to `schemas/value_objects/`, where `.proto` files import it. `protean ir diff` reports changes to it, and `protean check` reports `VALUE_OBJECT_MUTABLE_FIELD` and `DEPRECATED_ELEMENT` for it.
