`has_domain_context()` is exported from `protean`. It returns whether a domain context is active and never warns. Outside a domain context, dunder lookups on `current_domain` and `g` (such as the `__test__`, `__bases__` and `__class__` checks pytest makes while collecting a test module that imports them) no longer emit the "Working outside of domain context" warning. With pytest 8.4 and later, collecting such a module records no warning. Earlier pytest versions also read the non-dunder `_pytestfixturefunction` name, which still warns once. Truthiness, `repr`, `str` and ordinary attribute access still warn (#1632)
