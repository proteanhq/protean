**Breaking (test mode only).** `Engine(test_mode=True).run()` and `protean server --test-mode` stop as soon as every subscription has run out of work, instead of always running eleven 0.1-second cycles. Test mode also pauses at most 10 milliseconds between a subscription's ticks, so a broker subscription no longer waits its 1-second `tick_interval` to see new messages. The old limits still apply when a subscription keeps finding work or cannot report whether it is idle. Production engines are unchanged.

**Migration:** [The test-mode engine stops as soon as it is idle](https://docs.proteanhq.com/reference/migration/v0-18/#the-test-mode-engine-stops-as-soon-as-it-is-idle)
