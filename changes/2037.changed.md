[IR] **Breaking.** `.proto` generation raises `ValueError` naming both classes when two referenced value objects or entities with one class name would be declared in one file, or a referenced class has the name of the file's own element. Before, the generator kept one of the two messages and the other class's fields were lost. `generate_proto_schemas()` and `generate_proto_schema()` without `import_path` raise it for any such pair. `write_schemas` raises it when a file nests two types with one name, or nests a type with the name of the file's own element. A file nests only types with no file of their own, such as members of a reference cycle. Rename one of the two classes. (#2037)

**Migration:** [The standalone `.proto` generators are deprecated](https://docs.proteanhq.com/reference/migration/v0-19/#the-standalone-proto-generators-are-deprecated)
