`repository_for()` on a cache-backed projection now says which API to use instead of failing with `No provider configured with name 'None'`. That message named the wrong problem: the projection is not misconfigured, the caller is at the wrong door, and the working API had to be found by reading source. The error now reads: `` `Token` is cache-backed (cache='default'), so it has no repository. Use `domain.cache_for(Token)` to write and `domain.view_for(Token)` to read. `` Surfaced by the ShopStream reference app as a first-user friction point.
