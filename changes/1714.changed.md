The memory provider's `raw()` raises `DatabaseError` for a malformed query, where it raised a bare `Exception`; `DatabaseError` is still an `Exception`. Error logs from the observatory API, the server subscriptions and the worker supervisor no longer repeat the exception text in the message, because the logged traceback already shows it. The base classes' `__new__` and `__enter__` are annotated to return `Self`, so a type checker infers the subclass on construction.
