Fixed the `protean` CLI failing to start on a core-only install. The
`observatory` command imported `click` at module top, and the CLI loads every
command eagerly, so any `protean` invocation raised `ModuleNotFoundError: No
module named 'click'` unless the `server` extra (which pulls click in through
uvicorn) was installed. The import is now lazy, inside the command that needs it.
