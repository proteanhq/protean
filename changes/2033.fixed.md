[IR] **Breaking.** The IR records a value object's own `ValueObject` field as a `value_object` field with a `target`, and with `required` when the field is required. The IR writes the same entry for a field annotated with a value object class, such as `geo: Geo | None`. The IR used to record both as a `String`, so the Avro, JSON Schema and Protobuf schemas typed the field as a string. A value object now joins a cluster when a command or event holds it in a `Dict(value_type=ValueObject(...))` field. It also joins one when a placed value object holds it in a single-value or `Dict` field. The schemas used to write an empty object, record or message for these value objects. They now list the value objects' fields. A value object that declares `part_of` now always joins that aggregate's cluster. Before, a field on another aggregate could place it in that aggregate's cluster. `protean check` reports a `List` or `Dict` field on a newly placed value object as `VALUE_OBJECT_MUTABLE_FIELD`. (#2033)
