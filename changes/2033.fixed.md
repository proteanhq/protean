[IR] **Breaking.** The IR records a value object's own `ValueObject` field as a `value_object` field with a `target`, and with `required` when the field is required. A field annotated with a value object class, such as `geo: Geo | None`, gets the same entry. The IR used to record both as a `String`, so the Avro, JSON Schema and Protobuf schemas typed the field as a string. A value object now joins a cluster when a command or event holds it in a `Dict(value_type=ValueObject(...))` field. It also joins one when a placed value object holds it in a single-value or `Dict` field. The schemas now list the fields of these value objects, and used to write an empty object, record or message. A value object that declares `part_of` now joins that aggregate's cluster, even when a field of another aggregate holds the value object. `protean check` reports a `List` or `Dict` field on a newly placed value object as `VALUE_OBJECT_MUTABLE_FIELD`. (#2033)
