**Breaking.** The database port and its adapters now use the word "database". `protean.port.provider` is now `protean.port.database`, with `DatabasePort`, `RawQueryDatabasePort`, `DatabaseHealth` and `BaseDatabase`. `protean.adapters.repository` is now `protean.adapters.database`, and each adapter class ends in `Database`, such as `MemoryDatabase` and `PostgresqlDatabase`. `Providers` and `domain.providers` are now `Databases` and `domain.databases`, the registry instance is `databases`, and the entry-point group is `protean.databases`. The `provider` option on aggregates, entities, projections and subscribers is now `database`, and the `database` option on repositories and database models is now `database_type`. A renamed option raises `ConfigurationError` that names its replacement, and an old import path raises `ImportError`. The `protean.utils.Database` and `protean.utils.Cache` enums are removed. `domain.init()` now checks a repository's or database model's `database_type` against the adapters in the `protean.databases` registry, so a custom adapter's type is accepted. A broker class sets `broker_type` instead of `__broker__`. The `provider` configuration key and the IR keys do not change.

**Migration:** [The database port is named Database](https://docs.proteanhq.com/reference/migration/v0-19/#the-database-port-is-named-database)
