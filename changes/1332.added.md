Runtime invariant failures now carry a coded diagnostic. When an `@invariant.pre` or `@invariant.post` on an aggregate, entity, value object, or domain service fails, the raised `ValidationError` carries a stable `code` (and a `codes` list when several invariants fail together), plus the registry `rationale` and `fix`, so an agent or operator catching it gets an actionable steer. The errors dict is unchanged. Stamp your own code with `@invariant.pre(code=...)` / `@invariant.post(code=...)`.
