`RedisCache.flush_all()` now sends `FLUSHDB` instead of `FLUSHALL`, so it empties only the cache's configured Redis database and leaves the other databases on the server alone. The Redis and Redis PubSub brokers' `_data_reset()` test reset changed the same way.

**Migration:** [`flush_all()` on a Redis cache clears only its database](https://docs.proteanhq.com/reference/migration/v0-18/#flush_all-on-a-redis-cache-clears-only-its-database)
