**Breaking.** Paths that expect one kind of failure now handle only that failure, and any other error reaches the caller. They include no active domain context, a `[logging]` value that is not a table, and a closed health-check socket. The CloudEvents `source`, the access-log counters and the unit of work's access-log step check for a domain context before reading it, so they no longer emit the "outside of domain context" warning. The IR diff also accepts a removal version written as a number.

**Migration:** [Some internal fallbacks let unexpected errors through](https://docs.proteanhq.com/reference/migration/v0-18/#some-internal-fallbacks-let-unexpected-errors-through)
