Deprecated a `sequential_by` value on a process manager that is not a boolean. Before, any truthy value turned partitioning on, so a field name such as `sequential_by="order_id"` worked like `True` and the IR carried a string the schema does not allow. `domain.init()` now emits a `RemovedInProtean020Warning` and stores the value as a boolean, so the IR stays valid. The value raises in 0.20.0. Set `sequential_by=True` instead.

**Migration:** [A non-boolean `sequential_by` on a process manager is deprecated](https://docs.proteanhq.com/reference/migration/v0-18/#a-non-boolean-sequential_by-on-a-process-manager-is-deprecated)
