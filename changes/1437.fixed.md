`read("$all")` and `read_all("$all")` no longer raise `TypeError` when the store holds snapshots. Snapshot rows are written with no metadata, and deserializing them tripped over `None`; both readers now skip snapshot rows (type `SNAPSHOT`) and yield events and commands only. `read_all` pages on the raw store rows so an interleaved snapshot no longer truncates the read or desyncs the paging cursor. `read_last_message("$all")` also skips a trailing snapshot row and returns the newest event instead, so outbox reconciliation no longer crashes when a snapshot is the last row.
