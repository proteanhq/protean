**Breaking.** Removed the `database_model` option from `@domain.aggregate`, `@domain.entity` and `@domain.projection`, and from `domain.register()` for those elements. The option never had any effect: Protean built its own database model and the one passed was never used. Passing it now raises `ConfigurationError: Unknown option(s) {'database_model'}`. Register a custom model with `@domain.database_model(part_of=<Element>)` instead.

**Migration:** [The `database_model` element option is removed](https://docs.proteanhq.com/reference/migration/v0-18/#the-database_model-element-option-is-removed)
