An event or command rebuilt from a stored message, for example with `Message.to_domain_object()`, now keeps its stored `origin_stream`, even when it is empty. Before, the stored value was ignored. A rebuilt event took the `origin_stream` of the command being handled, if that command had one. A rebuilt command took the stream of the event being handled. In every other case, including an event or command delivered to its own handler, it came back as `None`. A new event or command still takes `origin_stream` from the message being handled: an event raised by an aggregate in a command handler takes that command's `origin_stream`.
