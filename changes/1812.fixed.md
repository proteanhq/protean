An event or command rebuilt from a stored message, for example with `Message.to_domain_object()`, now keeps its stored `origin_stream`, even when it is empty. Before, a rebuilt event took the `origin_stream` of the command being handled, a rebuilt command took the stream of the event being handled, and outside a handler the value was dropped. Events and commands built directly with `_metadata`, such as in a process manager transition, still take `origin_stream` from the message being handled.
