**Breaking (custom repositories).** The `DAO` service's write path lives in `protean.infra.dao_write`, and the service's `create`, `save`, `save_if_absent`, `update`, `delete` and `delete_all` delegate to it. The 0.18 `BaseDAO._apply_pre_persist_hooks` is now the public `DAO.apply_pre_persist_hooks`, and `BaseDAO._flush` is now the public `DAO.flush`. The unique-key helpers `_unique_key_indexes` and `_unique_key_criteria`, which `BaseDAO` held in 0.18, are private functions in `protean.infra.dao_write`. The write path keeps its guarantees: the optimistic-concurrency version check, the Unit of Work tracking, the pre-persist hooks and the unique-field checks behave as before.

**Migration:** [`BaseDAO` is split into `DAOPort` and the `DAO` service](https://docs.proteanhq.com/reference/migration/v0-19/#basedao-is-split-into-daoport-and-the-dao-service)
