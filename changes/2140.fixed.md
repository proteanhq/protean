`protean shell`, `protean server` and the `protean db` commands now find a domain at `src/<package>/domain.py` when run with no `--domain`, or with `--domain .`, so a project that `protean new` creates loads from its root. When more than one `domain.py` matches under `src/`, or more than one `subdomain.py` with no `domain.py` there, the command lists them and asks for `--domain`. With no `--domain`, a `subdomain.py` or a `subdomain` package in the current folder now loads too, and with `--domain .`, a `domain` or `subdomain` package does, as the docs describe.
