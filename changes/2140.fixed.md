`protean shell`, `protean server` and the `protean db` commands now find a domain at `src/<package>/domain.py` when run with no `--domain`, or with `--domain .`, so a project that `protean new` creates loads from its root. When more than one domain matches under `src/`, the command lists them and asks for `--domain`. With no `--domain` and with `--domain .`, a `subdomain.py` and a `domain` or `subdomain` package in the current folder now load too, as the docs describe.
