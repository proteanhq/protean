A failed pre- or post-invariant on an existing entity or aggregate now raises a `ValidationError` whose `messages` is a plain `dict`, the same type construction raises. Before, the update path returned a `defaultdict`, so reading a key that was not there gave `[]` instead of raising `KeyError`. (#1939)

**Migration:** [Invariant errors carry a plain `dict`](https://docs.proteanhq.com/reference/migration/v0-19/#invariant-errors-carry-a-plain-dict)
