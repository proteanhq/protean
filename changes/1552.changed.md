Hardened the twelve building-block teaching skills in the DX pack and wired them to the diagnostic contract.

The six element skills that teach a coded convention (`aggregate`, `value-object`, `command`, `event`, `command-handler`, `event-handler`) now declare the codes they teach under `metadata.diagnostic_codes` and name each code in the body, so a diagnostic can point at the skill that teaches its fix.

Fixed what the skills said about the framework. The aggregate config reference documents `database_model` (there is no `model` alias). The entity error message matches the framework's wording. The repository skill teaches the public `self.query`, `self.find_by()`, `self.find()` and `self.exists()` helpers, keeps `self._dao` as an internal escape hatch, and sends aggregation queries to the provider-level `raw()`, since `self.query.raw()` hydrates every row into a full aggregate.

Fixed what the skills said the checks measure. `AGGREGATE_TOO_LARGE` counts entity types in the cluster, not rows loaded at runtime. `HANDLER_PERSISTS_AND_CALLS_OUT` fires only on an external call that follows the first `repository_for(...)`. `VALUE_OBJECT_INVARIANT_FAILED` is the default code for a post-invariant declared without `code=`.
