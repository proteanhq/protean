Hardened the twelve building-block teaching skills in the DX pack and wired them to the diagnostic contract. The six element skills that teach a coded convention (`aggregate`, `value-object`, `command`, `event`, `command-handler`, `event-handler`) now declare the diagnostic codes they teach under `metadata.diagnostic_codes` and name each code in the body, so a diagnostic can point at the skill that teaches its fix. Fixed drift against the current framework: the aggregate config reference documents the `database_model` option (there is no `model` alias), the aggregate size rule states the real `aggregate_size_limit` default of 5, the repository skill teaches the public `self.query`, `self.find_by()`, `self.find()`, and `self.exists()` helpers with `self._dao` called out as an internal escape hatch, and the entity error message matches the framework's wording.
