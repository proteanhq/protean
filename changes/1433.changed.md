**Breaking.** The IR schema version moved from `0.1.0` to `0.2.0` to carry the new `method_edges` key. Schemas and documents validate both ways, and the `v0.1.0` schema stays published, but the checksum space changed: a committed `.protean/ir.json` baseline stamped `0.1.0` now makes `protean ir check` report a version mismatch and exit `3` (the `protean-check-staleness` hook prints the same message and fails) until you regenerate it.

**Migration:** [The IR schema is now v0.2.0](https://docs.proteanhq.com/reference/migration/v0-18/#the-ir-schema-is-now-v020)
