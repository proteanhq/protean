It covers round trips, TTL units, which TTL shapes are accepted and rejected, flush, remove, and key patterns. This mirrors the repository and broker generic suites. Where the two adapters behave differently today, the suite asserts the intended shared behaviour and marks the test as a strict expected failure naming its follow-up (#1391, #1392, #1393, #1399, #1401), so aligning them later turns the test green instead of leaving the gap unnoticed.
