Added `tests/adapters/cache/generic`, a cross-adapter test suite for the cache port that asserts each shared behaviour (round trips, TTL units, shape acceptance/rejection, flush/remove/pattern matching) once per test, against the memory adapter always and the Redis adapter too on the `--redis` leg, mirroring the existing repository and broker generic suites. Known divergences between the adapters (missing-key handling on `remove`/`remove_by_key`/`set_ttl`, `get_ttl`'s return shape on a missing key, glob-vs-regex key-pattern matching, and `remove_by_key_pattern` on a pattern that matches nothing) are encoded as strict expected failures naming their follow-up issues (#1391, #1392, #1393) or flagged for one, so a future alignment turns green instead of going unnoticed.
