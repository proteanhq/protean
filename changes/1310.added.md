Added `tests/adapters/cache/generic`, a cross-adapter test suite for the cache port that asserts each shared behaviour (round trips, TTL units and rejection, flush/remove/pattern matching) once against both the memory and Redis adapters in the same run, mirroring the existing repository and broker generic suites. Three known divergences between the adapters (`remove_by_key` on a missing key, `get_ttl`'s return shape on a missing key, and glob-vs-regex key-pattern matching) are encoded as strict expected failures naming their follow-up issues (#1391, #1392, #1393), so a future alignment turns green instead of going unnoticed.
