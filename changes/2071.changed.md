**Breaking.** A broker that declares `DEAD_LETTER_QUEUE` subclasses the new `DeadLetterQueuePort` and implements seven public methods: `dlq_list`, `dlq_get`, `dlq_replay`, `dlq_replay_all`, `dlq_purge`, `dlq_trim` and `dlq_depth`. The `_dlq_*` hooks, the public `dlq_*` wrappers on the adapter and the `dlq_trim` and `dlq_depth` defaults are removed, and `domain.init()` raises `ConfigurationError` for a broker that declares the capability without the port. On a broker without the capability, the `Broker` service returns an empty result for each DLQ call, and `dlq_trim()` still raises for a bad cutoff. `dlq_inspect()` is now `dlq_get()`, which also changes the observatory's OpenAPI operation ID for `GET /api/dlq/{dlq_id}`. `dlq_trim()` takes a timezone-aware `older_than` in place of a stream ID, raises `ValueError` for a naive one and `TypeError` for a value that is not a `datetime`, and the Redis broker now trims exactly. The inline broker keeps its DLQ as messages on `{stream}:dlq`, trims and counts it, and drops `get_dlq_messages()` and `reprocess_dlq_message()`. An inline entry's `dlq_id` is now its ID on the DLQ stream, and its `payload` includes `_dlq_metadata`. A stream subscription now records the time of the failure in an entry's `failed_at`, read from `domain.clock`, in place of the time the event was raised.
