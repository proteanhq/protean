`protean ir diff` now downgrades an event-sourced aggregate's breaking field removal or required-field add to safe when every rebuilding event that was version-bumped is covered by a registered upcaster, and at least one was bumped and covered. Replay rebuilds the aggregate, so those changes are earned-safe on the same terms as the events that replay it. A single uncovered bump among the rebuilding events, or no bump at all, leaves the aggregate breaking. A field type change stays breaking: a stored snapshot can still hold the old value in a shape the new field accepts, so the aggregate loads from that snapshot and never replays through the upcaster. A classic table-backed aggregate is never touched by this path; `exclude` stays the only escape hatch there.
