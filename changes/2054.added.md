[CLI] `protean test test-adapter` takes `--port` and `--config`. `--port broker`, `--port cache` and `--port event_store` run that port's suite under `tests/conformance/` against the adapter `--provider` names, once for the tests that need no flag (the `unmarked` row) and then once per capability flag, and report each flag the adapter does not declare as SKIP. `--port` defaults to `database`, which runs the database suite as before. `--config` merges a JSON object into the adapter configuration, and `--uri` sets `database_uri` for `database` and `event_store` and `URI` for `broker` and `cache`. On `--port database`, both set only the configuration that reads the provider's capabilities. `--capabilities` takes the port's capability flag names, such as `EXPECTED_VERSION` or `CRUD`. The command runs from a Protean source checkout. (#2054)
