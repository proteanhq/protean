**Breaking.** A projection now enforces a `ValueObject` field declared with `required=True`. Building the projection without the value object raises `ValidationError` keyed on the field name with `['is required']`, the same error an aggregate or entity gives. Before, the projection was built and the field stayed `None`. The field counts as given when the value object or any one of its shadow fields is passed, so records loaded from a repository or a cache load as before. A missing required value object and a failing Pydantic field are reported together in one `ValidationError`. A failed construction also no longer leaves an entry on the projection's thread-local init stack.

**Migration:** [Projections require their required value objects](https://docs.proteanhq.com/reference/migration/v0-19/#projections-require-their-required-value-objects)
