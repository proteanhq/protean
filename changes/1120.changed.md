Protean does not use strict semantic versioning. The versioning policy is now written down: code that runs warning-free on 1.N runs unmodified on 1.N+1, minor releases may remove APIs that were already deprecated, and majors are reserved for a categorical shift. See the new [versioning policy](https://docs.proteanhq.com/reference/versioning-policy/) page for the contract and how to enforce it in CI.
