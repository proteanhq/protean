Documented Protean's post-1.0 versioning policy. Protean will not use strict semantic versioning at 1.0; it uses a deprecation-managed model instead, with the contract "code that runs warning-free on 1.N runs unmodified on 1.N+1". A new [versioning policy](https://docs.proteanhq.com/reference/versioning-policy/) reference page states what each version position may contain and how to enforce the contract in your own CI. ADR-0004 records the reasoning for rejecting strict SemVer and what a major version is reserved for.
