[Docs] A new guide, [Run Schema Migrations](https://docs.proteanhq.com/guides/compose-a-domain/schema-migrations/), follows one table change from the dev box, through CI, to production with the `protean db` migration commands. It covers what autogenerate cannot detect, three ways to apply migrations to production, adopting migrations on an existing database with `alembic stamp`, and one migrations folder per provider. The production checklist in Configure for Production now points at the guide in place of `protean db setup`. (#2138)
