A value object, command or event that declares a nested value object in assignment style (`address = ValueObject(Address)`) and no annotations of its own no longer writes that field into `BaseValueObject`, `BaseCommand` or `BaseEvent`. On Python 3.11 to 3.13, once anything had read `ModelMetaclass.__annotations__`, the field landed on the base class and every value object, command or event defined afterwards gained it. Field resolution on entities, aggregates, projections and queries also reads only the class's own annotations now, so a subclass with no annotations stops copying its parent's.
