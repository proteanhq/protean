`DomainFixture.setup()` now pings every configured broker once and emits a `UserWarning` for each one that does not answer. The warning names the broker and its URI, with any password shown as `***`. Before, an unreachable broker showed up only as a connection error in the first test that published to it, because the per-test reset logs its own failure and carries on. `setup()` still returns normally; run pytest with `-W error::UserWarning` to make the warning fatal.
