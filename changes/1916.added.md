`DomainFixture.setup()` now pings every configured broker once and emits a `UserWarning` for each one that does not answer. The warning names the broker and its URI, with any password shown as `***`. Before, a suite whose tests never published to a down broker passed with no visible sign of it. The per-test reset logs its failure to clear the broker and carries on, and pytest shows that log line only for failing tests. `setup()` still returns normally; run pytest with `-W error::UserWarning` to make the warning fatal.
