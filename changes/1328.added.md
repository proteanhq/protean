Added a derived project manifest at `.protean/project.json`. `protean new` now writes it after generating a project, recording the package name, the domain name, and the ADR-0030 layout paths. Every field is recomputed from its own source on disk, so the file is derived and verifiable but never authoritative: `protean.scaffold.manifest.check_manifest_drift` recomputes the manifest and reports where a stored file disagrees with the code, changing nothing. See ADR-0034.
