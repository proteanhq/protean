**Breaking.** `protean new`'s dry run no longer touches the target directory. It used to clear the target when combined with `--force`, and to fail with `FileExistsError` on a non-empty target, both before it had rendered anything. The dry run now renders into a temp directory, prints the project-relative paths it would create (one per line, sorted), and leaves the target alone.

**Migration:** [`protean new --pretend` is now `--dry-run`, and it writes nothing](https://docs.proteanhq.com/reference/migration/v0-18/#protean-new---pretend-is-now---dry-run-and-it-writes-nothing)
