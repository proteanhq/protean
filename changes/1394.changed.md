`protean events catalog --json`, `protean subscriptions status --json`, and `protean projection status --json` now emit the shared CLI result envelope instead of a bare JSON array. The list moves under `data` (`data.events`, `data.subscriptions`, `data.projections`), and under `--json` stdout carries exactly one JSON object with logs on stderr. Usage and domain-load failures under `--json` are now the `status="error"` envelope on stdout and exit `2` (they printed a message and exited `1` before).
