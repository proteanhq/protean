Added `UNRAISED_EVENT`, an info-level `protean check` fitness function that flags a domain event declared in a cluster that no aggregate or entity method raises. It is the producer-side mirror of `UNHANDLED_EVENT`: where that rule finds events nothing consumes, this one finds events nothing produces. An event counts as raised when a single method both calls `raise_` and constructs it, so the factory idiom `user.raise_(Registered(...))` is recognized. Published events stay in scope, since they are still produced inside the domain. The rule fails open: a cluster whose classes the index cannot reach emits nothing.
