The IR records a `ValueObject` field on a command or event, and a field annotated with a value object class such as `addr: Address`, as a `value_object` field with the value object's `target` and its `required` flag, the kind and target the field gets on an aggregate. It used to record it as a `String`, so the Avro, JSON Schema and Protobuf schemas typed the field as a string while the message held an object. A value object that only commands and events hold now joins the cluster of the first such message's aggregate, so the schemas define it, `protean ir diff` reports changes to its fields, and `protean check` reports a `List` or `Dict` field on it as `VALUE_OBJECT_MUTABLE_FIELD`.
