The IR records a `ValueObject` field on a command or event as a `value_object` field with the value object's `target`, the same entry the field gets on an aggregate. It used to record it as a `String`, so the Avro, JSON Schema and Protobuf schemas typed the field as a string while the message held an object. A value object that only commands and events hold now joins their aggregate's cluster, so the schemas define it and `protean ir diff` reports changes to its fields.
