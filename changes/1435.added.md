`protean ir diff --format=event-model` renders the diff in EventModeling slice vocabulary. An added command is a new slice, a removed projection is a removed read model, a projection that gained a field is a changed slice, over the same snapshot loaders and exit codes as the text format. The `--format` option is now validated on `ir diff`, `ir show`, and `ir check`, so an invalid value fails with a message listing the valid formats instead of silently falling through to the default.
