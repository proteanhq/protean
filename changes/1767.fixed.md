The handler example in the domain services guide now runs against the guide's own `Order` and `Inventory` models. It loads each stock record with a query on `product_id` (the old `inventory_repo.get(item.product_id)` raised `ObjectNotFoundError`, because `product_id` is not the inventory's identifier), and it returns early for an order that is already confirmed, so a repeated `PlaceOrder` does not raise `OrderConfirmed` twice.
