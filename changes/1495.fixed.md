The mypy plugin makes field declarations type-clean under `mypy --strict`. `ValueObject` takes any class as its target, like the association fields, so `price: Money | None = ValueObject(Money)` type-checks with a decorated value object. `ValueObject(X, required=True)` and `Reference(X, required=True)` resolve to `X` instead of `X | None`, so `total: Money = ValueObject(Money, required=True)` is accepted and `self.total.amount` needs no `None` check. `default=None` no longer makes any field non-optional. The annotation-only form (`name: String(required=True)`) no longer reports `valid-type` or `call-arg` in a decorated element or a class that inherits a Protean base: the plugin replaces the rejected annotation with `Any` and accepts the field as an optional keyword argument.
