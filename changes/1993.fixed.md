An aggregate enricher now skips the records Protean saves for itself: outbox rows, the in-memory event store's message records, and consume-side idempotency markers. Before, an enricher that set a field such as `updated_by` failed every commit that raised an event, because those records have no such field. The memory event store failed this way with the default configuration, and the outbox failed the same way when it was on. An enricher that already skips aggregates without the field keeps working unchanged.
