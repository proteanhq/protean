`BaseAggregate._create_new()` and `from_events()` return `Self`, so an event-sourced factory method types as its own aggregate. `ReadView` is generic in its projection: `domain.view_for(ProductCard).get(...)` and `.find_by(...)` return `ProductCard`. A checker without the Protean plugin gets `ReadView[Any]`. `.query` results stay untyped by projection.
