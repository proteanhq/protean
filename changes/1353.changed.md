Widened the mutation-testing pass to the transaction, synchronous-dispatch, and checkpoint paths. `scripts/mutation.sh` gains three targets — `unit-of-work` (the `UnitOfWork` transaction boundary), `sync-dispatch` (breadth-first synchronous event dispatch, ADR-0016), and `checkpoint` (the `$all` gap-safe checkpoint path in `event_store_subscription.py`, scoped with `MUT_FILTER`) — and their surviving behavioural mutants are killed by new tests: the commit-time inline-dispatch guard only fires in sync mode, the public `dispatch_events_sync` fan-out runs and drains every pair, a `None` message context is removed rather than stored as `None`, the read-position checkpoint persists exactly at the interval, and the current-position write happens only when the store is behind. Tests only; no source or public-API change.
