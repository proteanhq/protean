Widened mutation testing to the transaction, synchronous-dispatch, and checkpoint paths. `scripts/mutation.sh` gains three targets — `unit-of-work` (the `UnitOfWork` transaction boundary), `sync-dispatch` (breadth-first synchronous event dispatch, ADR-0016), and `checkpoint` (the `$all` gap-safe checkpoint path in `event_store_subscription.py`) — each with tests that kill specific behavioural mutants: the commit-time inline-dispatch guard fires only in sync mode (and the event is still durably deferred in async mode), the public `dispatch_events_sync` fan-out runs and drains every pair, a `None` message context is removed rather than stored as `None`, the read-position checkpoint persists exactly at the interval, and the current-position write happens only when the store is behind. Running each new target to completion and driving down any remaining survivors is left as the next quarterly pass. Tests only; no source or public-API change.
