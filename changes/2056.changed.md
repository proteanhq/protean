**Breaking, custom event stores.** Event stores now implement `EventStorePort`, a `typing.Protocol` in `protean.port.event_store`. The memory store and the Message DB store subclass it. The private adapter methods have public names:

- `_write` is `write_message`.
- `_read` is split by scope into `get_stream_messages`, `get_category_messages` and `get_all_messages`. Its `no_of_messages` argument is now `limit`.
- `_read_last_message` is split into `get_last_stream_message`, `get_last_category_message` and `get_last_message`.
- `_stream_identifiers` is `stream_ids`.
- The event store's `_data_reset` is `clear`.
- `_stream_head_position` is removed; callers use `domain.event_store.category_head_position`.
- `MessageDBStore.client` is `get_connection()`.

An event store's constructor takes `(name, domain, config)`. The store keeps its settings in `config`, which replaces `conn_info`. The domain names its event store `default`. `read` no longer takes the unused `sql` argument.

Every event store has `ping()`, `health()` and `get_connection()`. The `/readyz` event store check calls `ping()`. Message DB now declares `CONSUMER_GROUPS`. Its `get_category_messages` passes `consumer_group_member` and `consumer_group_size` to Message DB. The memory store raises `NotSupportedError` when either argument is given. A memory category read of `user` no longer returns the rows of `poweruser-1`.

**Behaviour change, event handlers and projectors.** An event handler's `stream_category` and `source_stream`, and each of a projector's `stream_categories`, now get the domain prefix when the value has no `::`. `stream_category="all_orders"` in a domain named `ecommerce` registers as `ecommerce::all_orders`, which is the category an aggregate with `stream_category="all_orders"` writes to, so the handler reads the same streams on the memory store and on Message DB. `$all` and a value that contains `::` stay as written. An aggregate's own category is prefixed even when it contains `::`. A handler can no longer name a stream written without a domain prefix with a bare value; it subscribes to `$all` and filters, or a subscriber reads the stream. The handler's position and dead-letter streams move to the prefixed name. A memory category read of `user` now also returns the stream named `user`, as Message DB does.

**Behaviour change, raw memory store rows.** A row that the memory event store returns carries `time` as a `datetime`, as a Message DB row does. It used to be an ISO-8601 string.

**Migration:** [Event store `_write` is now `write_message`](https://docs.proteanhq.com/reference/migration/v0-19/#event-store-_write-is-now-write_message) and the sections after it.
