**Breaking, custom event stores.** Event stores now implement `EventStorePort`, a `typing.Protocol` in `protean.port.event_store`. `BaseEventStore` subclasses it. The private adapter methods have public names:

- `_write` is `write_message`.
- `_read` is split by scope into `get_stream_messages`, `get_category_messages` and `get_all_messages`. Its `no_of_messages` argument is now `limit`.
- `_read_last_message` is split into `get_last_stream_message`, `get_last_category_message` and `get_last_message`.
- `_stream_identifiers` is `stream_ids`.
- The event store's `_data_reset` is `clear`.
- `_stream_head_position` is no longer abstract.
- `MessageDBStore.client` is `get_connection()`.

An event store's constructor takes `(name, domain, config)`. The store keeps its settings in `config`, which replaces `conn_info`. The domain names its event store `default`. `BaseEventStore.read` no longer takes the unused `sql` argument.

Every event store has `ping()`, `health()` and `get_connection()`. The `/readyz` event store check calls `ping()`. Message DB now declares `CONSUMER_GROUPS`. Its `get_category_messages` passes `consumer_group_member` and `consumer_group_size` to Message DB. The memory store raises `NotSupportedError` when either argument is given. A memory category read of `user` no longer returns the rows of `poweruser-1`.

**Migration:** [Event store `_write` is now `write_message`](https://docs.proteanhq.com/reference/migration/v0-19/#event-store-_write-is-now-write_message) and the sections after it.
