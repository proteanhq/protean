**Breaking.** `protean schema generate --format avro` writes every `Identifier` field as a plain `"string"`, with no `uuid` logical type. An `Identifier` can hold any string, such as an email address, and a UUID-aware Avro reader rejected those values. The auto identity, Protobuf and JSON Schema already wrote a plain string. A schema registry that compares the generated `.avsc` files sees a changed type on each `Identifier` field.

**Migration:** [Avro schemas no longer mark `Identifier` fields as `uuid`](https://docs.proteanhq.com/reference/migration/v0-19/#avro-schemas-no-longer-mark-identifier-fields-as-uuid)
