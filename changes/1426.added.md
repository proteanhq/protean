Added Python 3.15 to the supported versions. The PyPI classifiers, the Nox sessions, and CI now include 3.15: per-PR CI runs the in-memory core suite on it and the nightly run adds it to the full adapter matrix. Both 3.15 legs are non-blocking while 3.15 is a prerelease, so a missing cp315 wheel upstream shows up as a warning rather than a failed required check. `setup-python` resolves the 3.15 line to its newest release candidate via `allow-prereleases`.
