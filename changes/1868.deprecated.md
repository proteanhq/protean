Twelve deprecations that said they would be removed in 1.0.0 now name a planned release. Removed in 0.19.0, with a new `RemovedInProtean019Warning`: the `is_event_sourced=` alias, the `published` option on a command, `@domain.email`, the `email_providers` config block, `Domain.get_email_provider()`, `Domain.send_email()`, the `Method` and `Nested` field types, the `pickled=` argument on `List`, and the `protean.utils.*` import shims. Removed in 0.20.0, with `RemovedInProtean020Warning`: `DAO.update()` and `QuerySet.update()`. `protean check` reports the new versions. `RemovedInProtean10Warning` still exists, but nothing emits it, so a filter that names it no longer matches these warnings.
