The adapter reference pages (brokers, caches, databases and the event store) now show code that runs. Their examples live in `docs_src/adapters/`, and tests run each one and check what it does. Running them turned up these errors on the pages, now fixed:

- Brokers: subscribers implement `__call__`, and are called on publish only when `message_processing` is `"sync"`. Publishing an empty message raises `ValidationError`. There is no `BrokerConnectionError`. When the client library raises a connection error outside a Unit of Work, the broker reconnects and retries once; the Redis broker's `get_next`, `ack` and `nack` handle errors themselves and return `None` or `False`. `health_stats()` returns `status`, `connected` and a broker-specific `details` dict. The `IS_ASYNC` setting is no longer in the docs, since nothing reads it. The default broker is `inline`, and the Redis Streams broker's provider name is `redis`.
- Redis Streams broker: it supports stream partitioning, takes connection pool settings (`max_connections`, `socket_timeout`, `socket_connect_timeout`, `retry_on_timeout`), and the `redis` version range now matches the one Protean installs.
- Redis PubSub broker: the page describes the list-based broker as it is. It drops a `MAXLEN` setting the broker does not read, a `PUBSUB NUMSUB` subscriber count that does not apply to lists, and the circuit breaker and compression samples. `ack()` returns `False`.
- Custom brokers and databases: the pages list every abstract method a broker or a provider implements. A provider sets `__database__`. Each page now has a working example adapter that delegates to the built-in in-memory one.
- Databases: custom models use `@domain.database_model`. Elasticsearch models use the `elasticsearch.dsl` module. Elasticsearch reads its `NAMESPACE_PREFIX`, `NAMESPACE_SEPARATOR` and `SETTINGS` options in upper case only, the default separator is `_`, and `database_uri` is a table (a quoted string must be JSON). Index settings come from `SETTINGS`; a custom model written as a plain class has its own `Index` class replaced. The PostgreSQL raw-query example names its table with `schema_name="users"`, because `user` is a reserved word. On MSSQL, `String()` has a default length of 255; only a primary key or `unique=True` column with no length raises. On MySQL, it is `max_length=None` that gives a `TEXT` column.
- Caches: the cache for a projection comes from `domain.cache_for()`.
- Event store: the examples use `domain.event_store.store` and real stream names. `at_version` counts from 0, `build_causation_tree()` takes a correlation id, the `[event_store]` config sample is valid TOML, and the `protean events` commands show their real arguments.
