**Behavior change:** `update()` and `QuerySet.update()` now persist through the same path as `save()`, so an update also refreshes `auto_now` timestamps and runs pre-persist aggregate enrichers — previously these fired only on `save()`/`repository.add`. (`auto_now_add` still stamps on create only.) This unifies the two persist paths and amends [ADR-0022](https://github.com/proteanhq/protean/blob/main/docs/adr/0022-pre-persist-aggregate-enricher.md). A new `apply_lifecycle=False` argument on `save()`, `update()`, and `QuerySet.update()` opts a raw write out of those hooks (optimistic-concurrency version management always applies, regardless of the flag). If you rely on `update()` *not* stamping timestamps or running enrichers, pass `apply_lifecycle=False`.
