A process manager now loads every transition in its stream. It read its stream with one `read`, which returns at most 1,000 messages by default, so a process manager with more than 1,000 transitions loaded an older version than its stream, and every later transition failed with `ExpectedVersionError`. The load now reads the stream with `read_all`. Other readers that need a whole stream now read all of it too: the `given(...)` test harness for aggregates and process managers, the Observatory's process instance list and the custom field conformance check use `read_all`; `protean events history` pages through the aggregate's stream; and the event store's `_last_event_of_type` and `_events_of_type` helpers page through `$all` or the category. The skills pack examples and the tutorials take the latest fact event with `read_last_message` or `read_all` instead of the last message of one `read`.
