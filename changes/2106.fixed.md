A process manager now loads every transition in its stream. It read its stream with one `read`, which returns at most 1,000 messages, so a process manager with more than 1,000 transitions loaded an old state and a version behind its stream, and every later transition failed with `ExpectedVersionError`. The load now reads the stream with `read_all`. The same complete read now backs the other readers that need a whole stream: the `given(...)` test harness for aggregates and process managers, the Observatory's process instance list, `protean events history`, the custom field conformance check, and the event store's `_last_event_of_type` and `_events_of_type` helpers.
