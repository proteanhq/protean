The event-store conformance suite in `tests/conformance/event_store/` checks any event store through the members of the event-store port: writes and positions, stream, category and global reads, the last-message reads, stream ids, expected versions, category commit order, consumer groups, durability, schema management and the store's lifecycle. Each test names the `EventStoreCapabilities` flag it needs, so `protean test test-adapter --port=event_store` reports one row per flag. The memory and Message DB tests that the suite now covers are removed. (#2063)
