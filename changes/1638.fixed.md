The `redis` adapter leg, and the `message-db` leg when a change selects it, now run the tests that carry two adapter markers, such as `postgresql` and `message_db`. Before, each leg passed one marker's flag, so these tests were skipped on every pull request and ran only in `protean test -c FULL`. An entry in `tests/adapters.toml` can list other markers under `enables`: its marker run passes their flags too. The `message-db` leg enables `postgresql` and `sqlite` and starts PostgreSQL, and the `redis` leg enables `postgresql` and starts PostgreSQL. When one `protean test` run holds both marker runs, the run of the enabled marker leaves those tests out, so they run once.
