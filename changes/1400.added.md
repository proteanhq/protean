ADR-0040 writes down the schema-evolution ladder: weak schema (`renamed_from`, and lenient mode to read payloads that carry a removed field) for additive and rename changes with no version bump; versioning plus an upcaster for structural changes, or a new event type when no value can be supplied for the new schema; and an operator-level migration for a long upcaster chain. It also records lenient mode as a permanent, off-by-default reader.
