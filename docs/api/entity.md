# BaseEntity

Base class for entities, domain objects with unique identity that live within
an aggregate. You always access an entity through its parent aggregate. An
entity cannot exist independently.

See [Entities guide](../guides/domain-definition/entities.md) for practical
usage and [Entities concept](../concepts/building-blocks/entities.md) for
design rationale.
