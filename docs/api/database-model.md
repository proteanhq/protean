# BaseDatabaseModel

`BaseDatabaseModel` is the base class for database models. A database model is
a persistence-layer data schema definition that maps domain aggregates to a
specific storage technology. Protean typically generates database models for
you, and you can customize them for adapter-specific optimizations.
